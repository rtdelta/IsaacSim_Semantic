# 挖掘机资产验收表

按 `SPEC.md` 对应 profile 使用。本文件是验收设计，不表示任何具体资产已经通过。结果枚举：passed / failed / not_tested / not_applicable；后两项必须说明原因。基础项 failed 或 not_tested 时不能发布为对应 profile 的 release。

| ID | 层次 | 必须核对的内容 | 合格证据 |
| --- | --- | --- | --- |
| A01 | 文件 | 入口、defaultPrim、单位、完整依赖、哈希、版本 | 依赖清单；干净路径下加载成功 |
| A02 | 组合 | 在 `/World/A` 与 `/World/B` 同时加载；不同位姿 | 两份内部关节/材质/传感器关系均指向各自实例，无串联 |
| A03 | 结构 | 唯一 root、5 刚体、4 关节和规定串联关系 | 组合后的角色、API、关系、DOF 名称报告 |
| A04 | 原点 | 基准点、坐标方向、版本、来源到最终系变换 | 数值变换 + 带标注的三视图，不以 AABB 代替定义 |
| A05 | 尺度 | 刚体及安装链单位 scale；几何注册只应用一次 | 五部件及臂长/锚点米制测量报告 |
| A06 | 关节 | 两侧锚点位置闭合、转轴一致、q 符号及零位 | 零位/有效 home/各关节 ±δ/组合姿态的 FK 对照 |
| A07 | 运动 | 原生 DOF 写入与回读正确，单一控制者 | +δ 测试，Hold、Pause/Resume、Stop/Play 后状态符合声明 |
| A08 | 初态 | 打开与 Play 初始化后 home 一致，无首次跳变 | 前后关节角及五刚体位姿快照；重力/驱动 profile 说明 |
| A09 | 几何 | Mesh、GS、斗齿和安装槽都随所属刚体运动 | 动前动后三视图及点/锚点世界坐标；无双重变换 |
| A10 | 传感器 | parent/mount/emitter 的实际组合变换、型号配置 | 矩阵与参数快照；若无传感器，明确 not_applicable |
| A11 | 射线 | 近处墙/车壳遮挡、self housing 策略、有效方向 | 指定测试场景的真实点云；不能只核对 nearRange 字段 |
| A12 | TF | 声明的帧树、原点/朝向、采样时刻 | 从实际消息核对 USD/FK 位姿；每 child 唯一 parent |
| A13 | 数据 | 所声明链路可录制、解包、按时间查 TF | 短包、逐话题帧率/字段/NaN统计、首末时间戳 |
| A14 | 持久化 | 临时调整恢复策略和明确保存策略 | 源文件前后哈希；重新打开后可复现；日志/快照定位 |
| A15 | 动力学 | 仅 dynamic_drive profile：质量、惯量、碰撞、驱动 | 数值合理性及所声明工况测试；prescribed 模式可不适用 |
| A16 | 消费者 | 每个声称兼容的项目及精确版本 | 单独配置、实际入口测试和结果，不互相代替 |

建议的**数值一致性验收阈值**（不是实机测量精度）：

- 静态关节中心闭合误差 ≤1e-4 m；转轴夹角 ≤1e-3 rad。
- prescribed 写入/回读角度误差 ≤1e-4 rad；刚体姿态 FK 对照平移 ≤1e-4 m、旋转角 ≤1e-3 rad。
- 传感器约定零外参的平移误差 ≤1e-6 m、旋转角 ≤1e-6 rad；也保存原始矩阵差，不只写 pass。
- 动态 TF 与同一时刻参考姿态：平移 ≤1e-4 m、旋转角 ≤1e-3 rad；报告时间匹配/插值规则。
- 频率按时间戳间隔统计；不要用含端点帧数除以区间长度。能否丢点取决于传感器/场景，不要求所有射线有回波。
- 浮点精度、模型尺寸或特殊工况需要不同阈值时，在测试前声明数值与原因，不在失败后无依据放宽。

有限运动范围内做 ±δ；零位不在允许范围时只做静态 FK 零位检查，不强行驱动至越限角。连续关节必须用清单声明的有限 operating 范围测试。正式长时间运行、动力学标定、几何真值或辐射标定需另行声明，不由这份最小验收推导。
