# 代码项目总结 Prompt

```text
请全面阅读并分析当前代码项目，包括源代码、目录结构、README、配置文件、依赖清单、构建脚本、部署文件、测试代码及相关文档，生成一份结构化的项目总结报告。

分析要求：

1. 以代码和项目文件中的事实为依据，不要凭空推测。
2. 重要结论请尽量注明对应的文件路径、模块名、类名或函数名。
3. 如果某项信息无法从项目中确认，请明确标注“暂未发现”或“需要进一步确认”。
4. 重点说明模块之间的调用关系、数据流转过程、核心业务逻辑和关键技术实现。
5. 配置参数应说明名称、位置、作用、默认值、是否必填以及可能的取值。
6. 输入和输出应尽量给出数据格式、字段含义及典型示例。
7. 如果发现潜在问题、技术债务或扩展限制，可以在对应章节中简要指出。
8. 使用清晰、准确、简洁的中文，避免只罗列文件，应总结其实际作用。

请严格按照以下结构输出：

# 项目总结

## 项目简介

说明项目要解决的问题、主要应用场景、目标用户、核心能力和整体技术定位。

### 项目职责

说明该项目在整个系统或业务链路中的职责，包括：

- 负责哪些业务或技术能力
- 不负责哪些内容
- 与外部系统或上下游服务的关系
- 项目的主要边界

### 当前迭代版本

说明：

- 当前版本号、分支或发布状态
- 当前迭代的主要目标
- 已实现的功能
- 正在开发或尚未完成的功能
- 可以从代码、提交记录或注释中识别出的版本变化

如果无法确认版本信息，请明确说明。

## 输入输出及配置参数

### 输入

列出项目接收的全部主要输入，包括但不限于：

- API 请求
- 命令行参数
- 消息队列事件
- 文件
- 数据库数据
- 用户交互
- 第三方服务返回值

对每类输入说明来源、格式、字段、校验规则及示例。

### 输出

列出项目产生的主要输出，包括但不限于：

- API 响应
- 页面或文件
- 数据库存储
- 消息队列事件
- 日志
- 状态变更
- 对第三方服务的调用

对每类输出说明目标、格式、字段、异常返回及示例。

### 配置参数

使用表格整理主要配置：

| 参数名称 | 所在文件或环境变量 | 类型 | 默认值 | 是否必填 | 作用 | 备注 |
|---------|------------------|------|--------|----------|------|------|

同时说明不同运行环境之间的配置差异，以及敏感配置的管理方式。不要输出真实密码、密钥或令牌。

## 组织架构

分析项目的目录和模块组织，建议使用目录树或分层结构说明：

- 各一级目录的作用
- 核心模块及职责
- 公共模块与业务模块的划分
- 模块之间的依赖关系
- 主要入口文件
- 关键类、函数或组件

不要简单复制目录结构，应重点解释其设计意图。

## 工作流

描述项目从启动到完成主要业务任务的完整过程，包括：

1. 项目启动和初始化
2. 配置加载
3. 输入接收
4. 参数校验与预处理
5. 核心业务处理
6. 数据存储或外部服务调用
7. 结果生成与输出
8. 异常处理、重试和日志记录

至少梳理一条最核心的业务链路，并注明涉及的模块、类、函数和文件。必要时使用 Mermaid 流程图或时序图表示。

## 核心要点

总结理解、维护和修改该项目时最需要关注的内容，包括：

- 核心算法或业务规则
- 关键数据结构和数据模型
- 主要设计模式
- 并发、缓存、事务或状态管理机制
- 异常处理和容错机制
- 安全与权限控制
- 性能关键点
- 测试策略及覆盖情况
- 已发现的风险、技术债务和注意事项

## 运行部署环境

说明项目运行和部署所需的条件：

- 编程语言及版本
- 框架和核心依赖版本
- 操作系统或基础镜像
- 数据库、缓存、消息队列等基础设施
- 构建工具
- 本地启动步骤
- 测试命令
- 构建命令
- 部署方式
- 容器、编排或 CI/CD 配置
- 健康检查、日志和监控方式

提供可执行的启动步骤，但不要编造项目中不存在的命令。

## 未来可能拓展

结合现有架构和代码实现，分析未来可能的扩展方向，包括：

- 新功能拓展
- 模块解耦或架构升级
- 性能与稳定性优化
- 可观测性完善
- 安全能力提升
- 测试和工程化改进
- 多环境、多租户或国际化支持
- 第三方系统集成

区分“代码中已有规划”和“根据现状提出的建议”，并说明每项建议的依据、收益、影响范围和可能难点。

## 总结

最后用简短内容总结：

- 项目的核心价值
- 当前成熟度
- 最关键的三个模块
- 最重要的三个风险
- 建议优先推进的三个事项
```

这份 Prompt 特别强调了“基于代码证据”“标注文件位置”和“不确定信息不臆测”，适合直接交给代码分析 Agent 使用。
