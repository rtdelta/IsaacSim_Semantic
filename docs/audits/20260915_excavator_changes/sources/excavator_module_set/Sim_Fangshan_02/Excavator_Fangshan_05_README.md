# Excavator_Fangshan_05：统一 2.4 倍的 Payload 资产

05 将 03 原始扫描部件统一等比例放大 2.4 倍，按缩放后的原始铰点重建装配。沿用 04 中来自 URDF 的关节拓扑、零角度方向、转轴方向和正向规则。关节安装平移和臂长使用 05 的新尺寸，不再等同于原 URDF。

## 原始 URDF 叠加对比（2026-09-14 新增）

主资产现在默认选择 `visualization = overlay_urdf`。打开 05 或其原有预览场景即可看到两套模型叠加：

- 青色半透明表面与轮廓线：原始 URDF STL，采用原始尺寸、原始关节安装位置和 q=0 姿态。
- 原色半透明扫描外观：05，各部件仍统一 2.4 倍。
- 青色关节点与连线：URDF 关节中心；橙色关节点与连线：05 关节中心。

两套模型的 base_link 坐标系重合。没有把 URDF 平移到 05 的新关节上，也没有重新缩放 URDF 来强行贴合。因此平台安装偏移、臂宽、驾驶室大小及铲斗轮廓的差异都会保留。

这是静止零位对比。请在时间线停止、05 关节处于零位时查看；青色 URDF 和对比关节点不会跟随 05 的运行时关节运动。正常试转时切回 `3dgs`，即可恢复原始不透明度并隐藏全部对比几何。

在挖掘机根节点的 Variants / visualization 中可选择：

| 选项 | 用途 |
|---|---|
| overlay_urdf（当前默认） | 05 与原始 URDF 完整零位叠加 |
| 3dgs | 单独显示 05，恢复原始 GS 不透明度 |
| urdf_original | 单独显示原始 URDF 完整零位 |
| source_mesh | 单独显示 05 扫描 Mesh |
| urdf_reference | 旧功能：原尺寸 URDF 单部件挂在 05 关节帧上；与 urdf_original 的整机安装位置不同 |

叠加模式把 GS 的每粒高斯不透明度乘以 0.08，仅用于看清内部 URDF；该值不是整机最终渲染透明度。原始 GS 文件未改动，切回 `3dgs` 会恢复全部原值。05 的 2.4 倍缩放、关节变换、驱动、物理占位参数均未改变。

新增显示依赖位于 `Excavator_Fangshan_05_data/overlay/`，搬迁时一并保留。该功能仍由 USD 的 Variant、Reference 和材质实现，无需启动脚本。叠加修改前的 05、说明和最终验证记录保存在该目录下的 `backup_20260914T082819Z/`；备份主文件的相对引用应在原资产目录位置解析。

透视叠加图为 `overlay/preview_overlay.png`，侧面叠加图为 `overlay/preview_overlay_side.png`。实际渲染与独立 Payload 对比检查记录见 `overlay/final_validation.json`。

## 加载

作为 Payload 引用的主资产：

```text
/root/gpufree-data/IsaacSim_Asset/excavator_module_set/Sim_Fangshan_02/Excavator_Fangshan_05.usda
```

直接打开查看的预览场景：

```text
/root/gpufree-data/IsaacSim_Asset/excavator_module_set/Sim_Fangshan_02/Excavator_Fangshan_05_preview.usda
```

主资产 defaultPrim 为 `/Excavator`，单位为米，Z 向上。引用时保持根节点 Scale=(1,1,1)，部件的 2.4 倍缩放已经写入资产。加载无需 sh、Python 启动脚本或回调。

主资产没有 PhysicsScene、相机、灯光或固定到世界的关节。预览场景通过 Payload 引用主资产，并提供零重力场景、灯光、相机及底盘固定关节。自己的场景需要提供相应的物理场景设置。

05 使用同目录 `3dgs_usd`、`waji_mesh_corrected.usdc` 和 `Excavator_Fangshan_05_data/urdf_reference_meshes.usdc` 的相对引用。搬迁时请保留这些依赖；无需携带 04 主资产。数据目录中的 Python 文件仅用于一次性构建与检查，资产加载不依赖它们。

## 缩放和部件组织

| 对应 link | 资产路径 | 原始部件统一倍率 |
|---|---|---|
| base_link | track_prim | (2.4, 2.4, 2.4) |
| swing_link | cab_prim | (2.4, 2.4, 2.4) |
| boom_link | boom_prim | (2.4, 2.4, 2.4) |
| arm_link | arm_prim | (2.4, 2.4, 2.4) |
| bucket_link | bucket_prim | (2.4, 2.4, 2.4) |

五个刚体下的 `Visuals/GS`、`Visuals/Mesh` 分别显式写入 Translate、Orient 和 Scale。原有非等比例缩放已被替换，没有在旧倍率上叠加 2.4。刚体坐标帧本身没有缩放。

铲斗壳体与 10 个斗齿共用同一个变换，原始相对位置保留；15 个 GS 分件的高斯数据、颜色、透明度和局部椭球参数均未改写。通过父级统一变换，中心间距和椭球尺寸一起等比例缩放。

`visualization` 选项：

- `3dgs`：统一 2.4 倍的扫描外观，原始不透明度；叠加功能加入后的默认显示为 `overlay_urdf`。
- `source_mesh`：统一 2.4 倍的扫描 Mesh，用分件颜色辅助检查结构。
- `urdf_reference`：保留原始米制大小的 URDF STL 单部件，作为尺寸标尺。这些标尺附着在 05 的 link 上，所以该显示不是原 URDF 整机运动学结果；它们不属于需要放大 2.4 的扫描部件。

## 关节与零位

四个关节沿用 URDF 的 `swing → boom → arm → bucket` 命名与父子关系，局部正轴均为 +Z。安装旋转沿用原 URDF，大臂关节 roll 为原始的 1.5707 rad。零位下回转轴为 base 的 +Z，后三轴约为 `(0,-0.999999995,+0.000096327)`。

| 关节 | 父 link | 子 link | 在父 link 中的安装 xyz / m |
|---|---|---|---|
| swing | base_link | swing_link | (0, 0, 0.525903702) |
| boom | swing_link | boom_link | (0.187003689, -0.546694413, 0.981823111) |
| arm | boom_link | arm_link | (5.750906244, 0, 0) |
| bucket | arm_link | bucket_link | (2.921875886, 0, 0) |

大臂原始轴心距 2.396210935 m × 2.4 = 5.750906244 m；小臂原始轴心距 1.217448286 m × 2.4 = 2.921875886 m。原 URDF 对应为 5.715 m、2.950 m。

所有 q=0 时，关节中心在 base_link 内的位置：

| 关节 | X / m | Y / m | Z / m |
|---|---:|---:|---:|
| swing | 0 | 0 | 0.525903702 |
| boom | 0.187003689 | -0.546694413 | 1.507726812 |
| arm | 5.937909933 | -0.546694413 | 1.507726812 |
| bucket | 8.859785819 | -0.546694413 | 1.507726812 |

平台到大臂的侧向偏移来自原资产的铰点数据，未强制归零。这样可同时保留平台的扫描比例和其安装点位置。

base_link 的 XYZ 方向沿用 04；XY 原点落在缩放后的回转轴上。Z 基准保留 04 底盘高斯中心包围盒的中心高度 0.105 m，不是地面或实测基准。05 底盘中心点最低高度约为 -0.505281 m；有地面时应按实际可见履带底部调整整机摆放高度，不能把根节点 Z=0 当作履带着地。

关节仍为无有限角度限位的 RevoluteJoint，对应源 URDF continuous。GUI 的 Angular Drive Target Position 用 degree；控制接口按各接口规定使用 rad。零位已存为零目标，不会因验证中的弯臂截图而改变。

## 验证和后续使用

- 所有 GS 分件的实际组合变换均为等比例 2.4；GS 和 Mesh 的配准变换一致。
- 四处父子几何锚点闭合，最大几何锚点与 USD 关节帧偏差约 2.23e-7 m，来自关节字段浮点精度。
- 29 组零位、单关节正负角度及组合角度，通过 05 的独立正运动学检查；转轴与 URDF 参考方向一致。
- 两处不同路径下的 Payload 引用通过关系重映射和组合检查。
- Isaac Sim 6.0.1-rc.7 中四关节各自 +10°、-10° 共八项驱动检查通过，最大稳态角度误差约 1.09e-6 rad。
- 三种显示和额外弯臂姿态在 Isaac Sim 中实际渲染。弯臂截图为会话层测试姿态，不是主资产默认姿态。
- 质量、惯量和驱动为预览占位值；没有新增碰撞体或实机动力学校准。

05 的角度约定可复用 URDF，但计算末端位置、逆运动学和工作范围时须使用 05 的安装参数。可读取数据目录中的 `kinematics_05.json` 或 `build_config.json`。

原有 48 个文件在构建前后进行 SHA-256 对照；03、04、原始 GS/Mesh 及旧预览资料保持不变。最终验收记录见 `Excavator_Fangshan_05_data/final_validation.json`。
