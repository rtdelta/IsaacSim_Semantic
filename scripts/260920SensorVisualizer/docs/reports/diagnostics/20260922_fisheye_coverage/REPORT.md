## 相机配置

四路均引用 `sensor_set/camera_set/fish_eye_camera/fish_eye_camera.usda`，使用 OpenCV fisheye 模型，1920×1080。按 fx、fy、cx、cy、k1～k4 反解像素中心边界：

- 中心水平截面：179.773°。
- 中心垂直截面：104.905°。
- 相对各相机光轴：向上约 52.445°，向下约 52.460°。
- 朝向相对 `swing_link` 为 +X、−X、+Y、−Y，各向下 10°。由于整机初始有轻微倾斜，世界俯角不同。
- 四路安装位置来自对应 MyAiry_front/back/left/right 的传感器原点。装配时复制位置，此后独立调整雷达不会自动更新相机。

使用 [OpenCV 官方鱼眼投影模型](https://docs.opencv.org/4.13.0/db/d58/group__calib3d__fisheye.html)，没有用旧 `aif:scaramuzzaPolynomial` 元数据或普通针孔公式替代当前渲染模型。

- 后：后方环境较开阔，未见大面积车体遮挡中心视野。

- 鱼眼边角存在黑区，不能把矩形图像每个像素都当作有效视线；非黑像素比例也不等于场景覆盖率。

## 覆盖示意图的适用范围

`ideal_ground_coverage.png` 使用当前磁盘姿态，将世界 Z=0 平面上的采样点投影进四个鱼眼模型，统计落入至少一幅图像的点。限制在光学正前半球，未执行 RTX 射线或几何遮挡测试。

灰色表示四路理论视场都未覆盖；蓝色深浅表示覆盖路数。灰区包含挖掘机占地及近旁区域，并非已经扣除车体轮廓的室外盲区。蓝区仍可能被车壳、大臂、铲斗或环境挡住。不能由本图给出实际无遮挡覆盖百分比。

若目标是近车地面的完整环视，后续应优先根据真实地面与车体轮廓调整俯角和安装高度，并在多个关节姿态下补做实际渲染验证。当前检查未改动任何安装参数。
