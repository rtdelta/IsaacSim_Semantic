两边 `desktop.conf` 都是 `command=/etc/gpufree`、`autostart=true`、`autorestart=false`。所以“退出后不自动重启”是共同配置，不能据此认定旧实例配置被改坏。

保留在进程文件描述符内的日志显示：旧实例桌面 15:23:22 启动，15:47:34 以状态 0 退出，随后 supervisor 因 autorestart=false 未重启它。新实例 16:38:43 启动后仍运行，桌面日志有 X Server ready、启动 Selkies、8081 就绪。退出状态 0 不说明是谁要求退出，也不证明全部子服务健康。

两边都存在 bootstrap/startup 服务提示，以及部分日志文件已删除但描述符仍打开的现象。这些共同现象不能单独作为旧实例故障或恶意清理证据。受检 cgroup 的 OOM 和 OOM kill 计数均为 0。
