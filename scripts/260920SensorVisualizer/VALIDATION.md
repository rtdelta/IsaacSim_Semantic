## 证据与边界

`geometry_validation.json` 记录全量素材和静态装配检查；`isaac_validation.json` 记录每组原生关节角、每部件位置/旋转/高斯采样误差；`deployment.json` 记录远端逐文件哈希和迁移后重新加载检查。

平台 roll/pitch 本版固定为零；质量/惯量/驱动为验证用途，没有动力学标定与碰撞网格。尚未接入雷达、ROS、MCAP，也没有运行同事的实际渲染程序。因此，本次通过的是“按提供的文档进行装配与运动”，不是双方整条采集链路的最终联调。

首次无窗口启动的失败来自既有 Python 字节码缓存，使用项目独立缓存命名空间后恢复。安装目录、现有 GUI 进程和旧挖掘机资产均未作此类修复或替换。
