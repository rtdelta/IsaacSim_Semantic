# v05 验证记录

2026-10-10 原生键盘与控制器重复运行修复已另外验证，见 [本轮修复记录](20261010_interaction_fix.md)。下文的 100 组/30 分钟结果来自 10 月 9 日，不是本轮重新测量。

日期：2026-10-09。设备：单 NVIDIA L40，约 46GiB 显存；CPU cgroup 配额 14 核。沿用 Isaac Sim 6.0.1-rc.7 与 ROS 2 Jazzy。

## 结论

网页控制、独立交互引擎和独立正式采集进程已实现并部署。100 组全质量采集及 30 分钟 GUI 引擎交互测试通过。并发采集时控制指令应用延迟 P95 约 38 毫秒，满足本轮 100 毫秒的 P95 目标；仍出现过约 0.61 秒的指令延迟和约 0.91 秒的引擎更新间隔，不能声称完全消除卡顿。

该延迟测量从引擎接收指令到实际应用回执，不等同于浏览器按键、网络、远程桌面和屏幕显示的完整端到端延迟。

## 未解决的警告与验收边界

- `omni.hydratexture.plugin was already released` 在 warmup/采集中反复出现，100 组测试共计 1632 次，不能归为仅退出时警告。当前数据解码通过，但其生命周期影响仍需跟进；本次没有修改 NVIDIA 插件或系统环境去掩盖警告。
- 仍观察到 Material 接口重复获取、空 SdfPath、VtArray 类型、Semantics 弃用、schema placeholder、animation graph 注册及 Fabric 接口兼容性等 SDK 警告；计数与原日志保留在报告目录。
- Motion BVH 关闭提示对应本项目固定姿态 Instant 采集策略；不是关闭基础 RTX BVH。本测试不涵盖运动畸变或滚动扫描。
- 云平台远程桌面的人工手感、真实原生按键焦点切换、输入框编辑需现场验收；通过 IPC 连续控制不等于真人键盘体验已经验收。
- 双 GPU 的实际设备绑定、吞吐与显存分配尚未验证；当前只有一张 L40。
- 严格 3DGS/LiDAR 几何对齐、GPU 纹理驻留和 LiDAR 内部 source frame ID 仍有证据边界，见架构文档。
- 用户暂缓依赖下载。标准库 HTTP 后端已测试；FastAPI/Uvicorn/WebSocket 可选入口尚未安装或运行验证。
