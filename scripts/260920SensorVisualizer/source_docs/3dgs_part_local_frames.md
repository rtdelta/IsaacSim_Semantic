# 3DGS 各部件局部坐标系、零位与原始素材变换

本文补充说明当前五份 3DGS PLY 与 `track_link`、`swing_link`、`boom_link`、
`arm_link`、`bucket_link` 的精确关系，供仿真、运动解算和素材处理人员统一零位。
TF 拓扑和发布规则以
[`3dgs_tf_simulation_contract.md`](3dgs_tf_simulation_contract.md) 为准。

## 1. 变换方向和坐标约定

- 遵循 ROS REP-103：`+X` 向前、`+Y` 向左、`+Z` 向上；
- TF 平移单位为米，角度接口使用弧度，本文为便于阅读同时列出角度制；
- 正角遵循右手定则；
- 记 `T_A_B` 为“把 B 坐标中的点变换到 A 坐标”；
- `T_parent_child` 的平移是子坐标系原点在父坐标系中的坐标；
- “初始角度”是当前 3DGS 绑定零位下的相对角，不是原 URDF 的绝对关节角。

当前渲染器使用 `capture_startup`，所以应先把全部相对关节角稳定在绑定零位，再启动
环视节点。当前 IMU 运动学节点的 `reference_mode=capture_startup` 也会把首组完整 IMU
姿态减为零。

## 2. 每个部件自身 TF 的零点和旋转

坐标系自身的零点按定义都是 `(0,0,0)`。下面说明这个零点在机械结构中的位置、
绑定时在 `base_link` 中的位置，以及允许的旋转。

| 3DGS 部件 | PLY | 所属 TF | TF 零点的机械含义 | 零点在 `base_link` 中 / m | 绑定姿态方向 | 允许旋转 |
|---|---|---|---|---:|---|---|
| 履带 | `track.ply` | `track_link` | `base_link` 原点，位于回转中心正下方 0.600 m | `(0.000, 0.000, 0.000)` | 与 `base_link` 平行 | 当前固定；以后只能由履带独立姿态接口驱动 |
| 回转平台 | `cab.ply` | `swing_link` | 履带与平台的中心回转轴 J0 | `(0.000, 0.000, 0.600)` | 与 `base_link` 平行 | `+Z` 回转，并可叠加平台 roll/pitch |
| 大臂 | `boom.ply` | `boom_link` | 平台与大臂根部主销 J1 | `(-0.374, -0.270, 1.554)` | 与 `swing_link` 平行 | 只绕父系/本零位 `+Y` |
| 小臂 | `arm.ply` | `arm_link` | 大臂与小臂主销 J2 | `(4.176, -0.336, 4.752)` | 与 `boom_link` 平行 | 只绕父系/本零位 `+Y` |
| 挖斗 | `bucket_without_teeth.ply` | `bucket_link` | 小臂与挖斗根部主销 J3 | `(5.402, -0.429, 2.090)` | 与 `arm_link` 平行 | 只绕父系/本零位 `+Y` |

绑定零位时所有固定 RPY 都是 `(0°,0°,0°)`，所以五个部件坐标系的 `+X/+Y/+Z`
都与 `base_link` 对齐。这里的“平行”只描述绑定零位；运动后子坐标系会继承所有
父关节旋转。

## 3. 每段 TF 的初始平移和角度

| 父 TF → 子 TF | 初始固定平移 / m | 固定 RPY / ° | 初始关节角 | 动态轴 | 初始四元数 `(x,y,z,w)` |
|---|---:|---:|---:|---|---:|
| `base_link -> track_link` | `(0.000,0.000,0.000)` | `(0,0,0)` | 无动态角 | 当前无 | `(0,0,0,1)` |
| `base_link -> swing_link` | `(0.000,0.000,0.600)` | `(0,0,0)` | `q_swing=0` | `+Z` | `(0,0,0,1)` |
| `swing_link -> boom_link` | `(-0.374,-0.270,0.954)` | `(0,0,0)` | `q_boom=0` | `+Y` | `(0,0,0,1)` |
| `boom_link -> arm_link` | `(4.550,-0.066,3.198)` | `(0,0,0)` | `q_arm=0` | `+Y` | `(0,0,0,1)` |
| `arm_link -> bucket_link` | `(1.226,-0.093,-2.662)` | `(0,0,0)` | `q_bucket=0` | `+Y` | `(0,0,0,1)` |

运动矩阵为：

```text
T_base_swing = Translation(0,0,0.600)
               × Rz(q_swing) × Ry(platform_pitch) × Rx(platform_roll)

T_swing_boom = Translation(-0.374,-0.270,0.954) × Ry(q_boom)
T_boom_arm   = Translation( 4.550,-0.066,3.198) × Ry(q_arm)
T_arm_bucket = Translation( 1.226,-0.093,-2.662) × Ry(q_bucket)
```

平移写在旋转之前，表示关节先放到固定销轴位置，再绕该子坐标系原点旋转。运动中
这些平移不得改变，也不能为了补偿模型接缝而加入动态平移。

全部关节为零时，累积结果为：

| TF | `base_link <- TF` 平移 / m | `base_link <- TF` RPY / ° |
|---|---:|---:|
| `track_link` | `(0.000,0.000,0.000)` | `(0,0,0)` |
| `swing_link` | `(0.000,0.000,0.600)` | `(0,0,0)` |
| `boom_link` | `(-0.374,-0.270,1.554)` | `(0,0,0)` |
| `arm_link` | `(4.176,-0.336,4.752)` | `(0,0,0)` |
| `bucket_link` | `(5.402,-0.429,2.090)` | `(0,0,0)` |

## 4. 原始 3DGS 素材的公共坐标变换

五份 PLY 是同一次重建拆出的部件，共用同一个原始重建坐标系。没有把各份 PLY
重新以关节为原点，也没有改写 PLY 文件内容。当前只在 GPU 模型矩阵中统一应用：

```text
p_base = 2.40 × R_raw_to_base × p_raw
         + (3.20352, -0.34217, 2.04934)

RPY_raw_to_base = (-103.98993°, -5.69811°, 61.29154°)
旋转顺序        = Rz(yaw) × Ry(pitch) × Rx(roll)
四元数 xyzw     = (-0.661468675, -0.427478193,
                    0.279772479,  0.549043665)
```

旋转矩阵为：

```text
R_raw_to_base =
[ 0.477979509,  0.258312253, -0.839529850 ]
[ 0.872741483, -0.031626896,  0.487157104 ]
[ 0.099286926, -0.965543639, -0.240556827 ]
```

包含 `2.40` 等比缩放后的完整齐次矩阵为：

```text
T_base_raw =
[ 1.147150821,  0.619949408, -2.014871640,  3.203520 ]
[ 2.094579558, -0.075904550,  1.169177049, -0.342170 ]
[ 0.238288623, -2.317304734, -0.577336385,  2.049340 ]
[ 0,            0,            0,            1        ]
```

原始素材三根正轴变换到 `base_link` 后的单位方向为：

| 原始素材轴 | 在 `base_link` 中的方向 |
|---|---:|
| 原始 `+X` | `(0.477979509, 0.872741483, 0.099286926)` |
| 原始 `+Y` | `(0.258312253,-0.031626896,-0.965543639)` |
| 原始 `+Z` | `(-0.839529850,0.487157104,-0.240556827)` |

这就是原始素材曾经“侧躺”的原因：原始重建轴不是 ROS 的前、左、上。当前公共
旋转将其转换为 ROS 方向，统一缩放 `2.40`，再平移到履带接地和回转中心位置。

## 5. 各部件相对于自身 TF 的等价素材变换

正式 YAML 中五个 `parts[].asset_transform` 都未设置，因此其配置值全部是严格单位
变换：

```text
translation = (0,0,0)
RPY         = (0°,0°,0°)
scale       = 1.0
```

公共 `reconstruction_to_base` 在它们之后统一应用。为了让素材或仿真人员明确“原始
PLY 放进各自 link 后是什么偏移”，下表给出绑定零位下的等价 `T_link_raw`。如果将来
把 PLY 真正转换成 link-local 文件，可使用此表；当前运行时没有把这些数写回 PLY。

| 部件 TF | 原始 PLY 零点在该 TF 中的平移 / m | 原始 PLY 到该 TF 的 RPY / ° | 等比缩放 |
|---|---:|---:|---:|
| `track_link` | `(3.203520,-0.342170, 2.049340)` | `(-103.98993,-5.69811,61.29154)` | `2.40` |
| `swing_link` | `(3.203520,-0.342170, 1.449340)` | `(-103.98993,-5.69811,61.29154)` | `2.40` |
| `boom_link` | `(3.577520,-0.072170, 0.495340)` | `(-103.98993,-5.69811,61.29154)` | `2.40` |
| `arm_link` | `(-0.972480,-0.006170,-2.702660)` | `(-103.98993,-5.69811,61.29154)` | `2.40` |
| `bucket_link` | `(-2.198480,0.086830,-0.040660)` | `(-103.98993,-5.69811,61.29154)` | `2.40` |

计算关系为：

```text
T_link_raw(bind) = inverse(T_base_link(bind)) × T_base_raw
```

因为绑定零位下所有 link 的旋转都为单位阵，所以表中五个局部素材旋转相同，只有
平移因各 link 原点不同而变化。

## 6. 各 TF 零点在原始 PLY 坐标中的位置

如果需要在原始 PLY 或 SuperSplat 中直接标记关节中心，应使用下面的原始重建坐标，
不能直接使用以米表示的 `base_link` 坐标：

| TF 零点 | 原始 PLY 坐标 |
|---|---:|
| `track_link` 零点 | `(-0.598360, 0.475165, 1.395468)` |
| `swing_link` / J0 | `(-0.573538, 0.233779, 1.335329)` |
| `boom_link` / J1 | `(-0.706740,-0.186720, 1.315729)` |
| `arm_link` / J2 | `(0.307729,-0.982720,-0.609818)` |
| `bucket_link` / J3 | `(0.407952,0.221409,-0.790738)` |

反算公式为：

```text
p_raw = transpose(R_raw_to_base)
        × (p_base - translation_raw_to_base) / 2.40
```

## 7. 运行时如何让共坐标 PLY 分部件运动

渲染器对第 `i` 个部件实际使用：

```text
M_i(t) = T_base_link_i(t)
         × inverse(T_base_link_i(bind))
         × T_base_raw
         × T_part_asset_i
```

当前 `T_part_asset_i=I`。因此：

- 绑定时刻 `T_base_link_i(t)=T_base_link_i(bind)`，五份 PLY 都按同一个
  `T_base_raw` 拼回原始重建状态；
- 运动后只把该 link 相对绑定时刻的刚体增量施加到对应 PLY；
- 父关节运动通过 TF 树自动传递给全部后代；
- 无需也不能在仿真端再次添加公共 RPY、`2.40` 缩放或素材平移。

## 8. 相对于原始素材实际做了哪些改动

### 8.1 已做的运行时改动

1. 对全部 Gaussian 中心统一施加 `2.40` 等比缩放、公共旋转和公共平移；
2. 对 Gaussian 各向异性椭球轴施加同一个模型矩阵，使位置和椭球方向同步；
3. 按部件 TF 相对绑定姿态的增量分别运动五份 PLY；
4. 球谐颜色计算使用模型矩阵的逆方向转换视线，保持训练时的视角相关外观。

### 8.2 没有做的改动

- 没有改写五份原始 PLY；
- 没有逐部件非等比缩放；
- 没有单独拉长大臂、小臂或挖斗；
- 没有修改 Gaussian 数量、中心、原始 quaternion、opacity 或 SH 系数；
- 没有把公共素材变换发布为 ROS TF；
- 没有在关节运动中加入平移补偿。

## 10. 对接时最容易混淆的三点

1. TF 原点是关节中心；PLY 文件的 `(0,0,0)` 不是关节中心；
2. 表 5 的局部素材偏移是当前公共变换的等价解释，不是需要仿真再次发布的 TF；
3. 当前 3DGS 初始关节角全部为零；如果上游只有 URDF 绝对角，必须先减去绑定绝对角
   并处理轴向符号，再作为当前 3DGS 相对角发布。
