# 连续采集与原 v06 冻结采集：先采集后比较实验方案

日期：2026-10-14，Asia/Shanghai。版本：1.0。状态：实验设计，尚未执行；本文列出的新增工具为待实现项。

本方案不以 450 组为固定规模。先使用当前连续链路保存真实输出、失败事件及实际状态，再让原 v06 冻结链路采集相同目标状态，最后进行配对比较和独立几何检查。采样规模由运动覆盖、独立重复、分析所需样本和预先声明的资源预算决定。

实验允许在尚未找到根因时收集连续链路的实验数据。位姿超限不应使这些诊断样本被过滤掉；正式数据的同步门槛和 READY 发布规则仍按原验收契约执行。实验采集完成、两版效果接近、连续主路线验收通过是三个不同结论。

## 1. 实验要回答的问题

按优先级回答以下问题：

1. 当前连续链路实际产生什么数据：完整组、缺路、重复、位姿超限、几何超限各有多少，发生在什么运动和运行阶段？
2. 相同实际状态下，原 v06 冻结输出与连续输出的差异有多大，是否影响点云与图像的实际用途？
3. 冻结输出、连续输出分别与独立已知几何是否一致？两条使用相同 SDK 的路径不能相互充当绝对真值。
4. 偏差主要关联旋转增量、历史取样、原生输出转换、产品组合还是保存负载？
5. 哪个后续小实验能够区分剩余机制，而不是继续无差别延长采样？

第一轮的交付目标是取得可解释的真实产出和差异范围。若仍无法确认内部故障函数，应交付有依据的机制范围和最小复现，而不强求从一次比较得出确定根因。

## 3. 两条主要实验路径与比较原则

### 3.1 连续路径 C：先保存当前行为

使用 `single0601ContinuousRt` 当前常驻 RenderProduct/Writer、连续播放和原生事件路径。第一轮不引入逐目标冻结、逐组 16+2 预热、固定姿态补偿或新的渲染 rig。

新增 `experimental_capture` 入口复用当前运动和传感器组件，在原生完成回调内取得独立拥有的 CPU 载荷。它保存符合布局和来源要求的载荷，即使后续位姿或几何检查不合格；同步错误与缺失另行记账。无法合法解码或没有独立所有权的 buffer 只记录拒绝原因，不冒险保存悬空指针。

正式 `recording.py` 的能力门槛不改成恒通过，不伪造 `continuous_verified`。实验目录只允许 `EXPERIMENT_COMPLETE`、`EXPERIMENT_PARTIAL` 或 `EXPERIMENT_FAILED`，没有正式 READY。实验状态与各项质量结论分开。

### 3.2 冻结路径 F：后采集相同实际状态

原 v06 选择 `offline`，重放 C 已记录的完整目标状态。主要对照固定为 `persistent_gated + keepalive`、16 相机冻结预热子帧加 2 正式子帧；原默认 `gated` 作为单独补充条件，不混入主要结果。

使用原 v06 的实际 `SceneStepper`、传感器驱动和记录模块，新增驱动或只读观测代码放在本实验项目内。保存原模块源码哈希和适配代码哈希，明确它是“原 v06 采集模块 + 实验驱动”，不能声称入口与原应用运行完全相同。

F 保留原有采集校验和有限重试，保存全部重试原因和耗时。原规则拒绝的尝试可由观测旁路保留诊断证据，但不能作为原 v06 的正式通过组。原规则接受的输出还需经过本实验共同指标检查。

### 3.3 配对依据是实际状态与显式来源映射

配对主键建议为：

```text
(experiment_id, repeat_id, source_epoch_id, source_target_step, sensor_id)
```

C、F 各自保存真实运行 epoch、原生 frameId、原生时间和渲染引用。F 的新 frameId 或绝对仿真时间不需要与 C 数值相等；通过 `pair_map` 将其对应到 C 的源目标。不同 RenderProduct 的 frameId 也不要求相等。

不能按文件顺序、回调序号或最近邻时间匹配。不能把两侧 header 改成相同值来制造同步证据。原生缺失字段保留 null，项目计数不替代原生帧号。

如果 C 某目标缺少载荷，但实际状态账本完整，F 仍采集这个目标；该目标进入 C 缺失统计。不能只重放 C 成功保存的目标。

## 4. 实验分层与采样规模

### 4.1 实验矩阵

| 阶段 | 场景和传感器 | 目的 | 扩展条件 |
|---|---|---|---|
| E0 准备与短样本 | scene18，1 相机 + 1 LiDAR | 核对原始保存、状态账本、目标映射、F 重放和资源估计 | 文件可回读，配对状态可验证；不要求 C 位姿通过 |
| E1 主配对实验 | scene18，1 相机 + 1 LiDAR | 先取得 C 真实产出，再与 F 对比 | 按完整预定运动块执行，包括失败样本 |
| E2 独立几何诊断 | 已知非对称房间，单 LiDAR；相机另用已知标记 | 测绝对几何误差，分离原生头与载荷偏差 | 分析器可观察半步/一步错配，坐标规则已验证 |
| E3 模型与安装扩展 | scene18，逐个增加模型与安装类型 | 判断是否为某型号或安装路径特有 | E1/E2 的计数和分析方法可信 |
| E4 全组合产出 | scene18，4 相机 + 13 LiDAR | 观察多路完整性、实际画质和负载相关偏差 | 全组合有独立资源预算；失败仍可做实验 |
| E5 有针对性的干预 | 从 E1–E4 中选最小失败用例 | 区分剩余机制 | 每次只改一个主要变量，并取得实际有效值 |
| E6 性能与长期资格 | 已通过共同正确性条件的路径 | 测合格产能和长期行为 | 沿用原验收规模，不能由诊断完成直接放行 |

E2 的纯 USD 最小房间没有原 v06 所需的机器人结构，不能直接套用原应用入口。需要独立冻结参考驱动：暂停物理推进、应用目标传感器位姿、保持状态、取得新原生事件。其结果标记为 `F_room`，只用于最小机制诊断，不冒充原 v06 scene18 产出。E1/E4 的 F 才承担原 v06 对照结论。

### 4.2 运动块

以下规模为首轮建议默认值，可在 E0 后依据预算调整；不构成固定总组数。调整必须在该轮开始前写入配置，不根据已看到的偏差临时删减运动段。

| 运动块 | 初始建议覆盖 | 要观察的现象 |
|---|---|---|
| 静止 | 5 秒仿真时间 | 基础误差、重复性和初始稳定过程 |
| 纯平移 | 0.3m/s，至少 10 秒；必要时补 1m/s | 与旋转路径分离，检验位置和坐标变换 |
| 低速纯旋转 | 3°/s，至少 10 秒；正反方向分别覆盖 | 单独复现小角度逐步更新 |
| 较快纯旋转 | 10°/s，至少 10 秒；正反方向分别覆盖 | 对照每步角增量和边缘/显露质量 |
| 低速混合 | 0.3m/s + 3°/s，至少 10 秒 | 重现已有失败特征 |
| 加减速与反转 | 预先给定平滑速度曲线，至少两个完整周期 | 区分固定角偏差与状态历史滞后 |
| 停留后恢复运动 | 至少三个“运动—停留—运动”周期 | 观察历史收敛和再启动过程 |
| 暂停恢复 | 初始建议五次，保存每次恢复后的前三个新事件 | 验证真实恢复载荷，不只验证时钟继续推进 |
| 关节与遮挡 | scene18 中至少两个完整运动周期 | 安装层级、关节传播与遮挡显露 |

基础物理/loop 为 60Hz，传感器 tick 为 10Hz。E1–E4 不使用 5Hz 抽取代替完整 10Hz 事件，否则可能隐藏周期性错误。每个运动块默认至少三次独立初始化重复；连续块和独立重启块分开报告，避免把重启影响并入稳态。

第一轮采用预定短块，在同一会话内连续切换运动并记录边界；另用独立会话重现关键块。暖机事件保留并标记，稳态统计预先指定排除范围，不能把初始失败悄悄删除。

### 4.3 规模与停止条件

采样目标由配置中的运动时长、采样频率及边界定义计算，不按“通过样本数”停止。发生几何超限时继续执行剩余预定块；观察到错误不是自动停止条件。

以下情况停止该轮并保留前缀：原始所有权失效、状态账本不可追溯、磁盘或预定预算不足、进程故障、无法取得有效事件、场景越界导致既定几何模型失效。报告原请求范围、实际覆盖、终止原因及未采目标。

E0 后锁定事件等待、初始化、整轮墙钟和资源预算。超过预算不代表仿真数据必然错误，但该轮不能声称完整执行。若需扩大预算，创建新的轮次和配置版本，不覆盖失败记录。

最小房间轨迹必须预检安全范围。现有 0.3m/s、3°/s 从原点连续运行约 37.8 秒会越过 `y=8m` 边界；采用有限运动块、受控闭合轨迹或新的已知几何范围，不能把越界后输出纳入同一室内平面拟合结论。

## 5. 先采集后比较的执行步骤

### P0：冻结实验条件并验证分析方法

保存 `experiment_spec.json`：源码、实际 SDK/GPU/驱动、根 USD 及依赖哈希、Session 层、选择集、安装标定、噪声、Instant/scan/tick、渲染有效设置、运动块、种子、统计方法、预算和停止条件。

静态场景优先用于状态配对。动态物体、随机化或时间驱动资产必须记录其实际状态并能够在 F 重放；无法复现的部分单独标记。固定随机种子不等于已证明原生噪声逐点完全相同，需通过重复冻结采集估计其自然差异。

用已有可追溯数据或短样本验证坐标约定、单位、矩阵布局和分析器。加入真实前一物理步错配负对照；半步检查可在解析已知轨迹中构造，明确标记为合成分析样本，不能替代实采。若负对照不能被识别，先修正实验测量方法。

### P1：运行 C，保存完整实际状态和原始产出

运动按物理时钟执行。每个物理 POST 保存实际 root、关节、安装及传感器世界矩阵，包含预定目标之外的邻接物理步；命令状态另存。状态必须先于相关渲染完成回调产生，不能回调中读取最新 USD 代替历史。

长期状态账本流式落盘。内存 `StateLedger` 只作有界事件关联缓存，不将其 1024 条记录上限当作整次实验历史保存能力。

每个目标分别记录：计划存在、各路原生事件存在、载荷保存成功、时间可映射、位姿可分析、几何可分析、文件可回读。重复事件和迟到事件保留其身份，不自动覆盖第一次事件。来源无法确定的载荷标 `unassigned`，不猜测目标归属。

暂停期间不能把重复缓存当新样本。恢复阶段显式开启新事件收集，并依据原生事件和源时间判定；现有 `phase != moving` 过滤逻辑需要相应扩展。

### P2：结束 C，排空并冻结输入证据

停止目标调度，完成已接收自有载荷的保存和文件关闭，独立回读文件并验证大小、哈希及布局。保留没有完成保存的事件和其原因。

冻结目标清单与实际状态清单。完成 C 自有资源清理后运行 F，避免两套 Kit 同时争用 GPU。后续分析不得修改 C 原始文件。

### P3：构建精确重放输入

新增 `export_pair_trajectory.py`，为每个源目标生成明确的 `source_state_id` 和映射表，完整保留实际 root 四元数、位置、关节、安装、传感器矩阵及必要场景状态。

原 v06 `Trajectory.sample()` 会进行位置/关节插值和 SLERP，并生成新的 snapshot ID。两种实施方法按优先级选择：

1. 实验驱动逐条应用已记录的目标快照，使用原 v06 采集模块，显式保存源目标映射。
2. 使用现有 offline 入口，但预先逐目标验证时间查询落在原始记录端点，采样结果与源状态一致；达不到时该目标不具备配对资格，不能用近似重放冒充同状态。

采用整数物理步和有理数相对时间构造网格。保存初始偏移、首目标、末目标、epoch 边界和实际裁剪情况。C 的缺失目标仍在重放输入中。不同 epoch 分开驱动，不跨时间回退插值。

### P4：运行 F，验证应用状态后采集

逐目标：推进 F 自己的原生时钟到合法采样边界，应用源实际快照，读取目标状态，冻结，按原 v06 条件预热与采集。重放一致性初始门槛为位置不超过 10μm、旋转不超过 1e-6rad、关节不超过 1e-6rad；它们是本实验新增的输入资格条件，需在 E0 验证数值可实现性后冻结。

该输入门槛必须明显小于被研究的半步/一步偏差。若目标传感器世界矩阵不一致，应先解决重放映射或标为不具备配对资格；不能将该差异算作连续采集错误。安装与内参要求一致，不以宽容差掩盖标定变化。

F 自己的原生源时间仍按原规则核验，原轨迹/native 约半物理步的允许映射误差不能当作 C/F 输入同状态的证明。每个目标保存输入快照、应用后实际读回、原生时间、首次输出及全部重试记录。

### P5：独立比较并发布实验报告

分析器只读 C/F 原始文件和映射。先报告所有计划目标的覆盖与资格，再报告可配对目标上的差异。按传感器、运动块、运行阶段和重复轮次拆开统计；全局平均值不能替代这些结果。

不能通过旋转点云、移动时间戳或重新配准后再给原始采集通过结论。可以在派生诊断中估计“需要怎样的位姿修正才能对齐”，但必须同时报告原始误差、估计方法和不确定性。

| 实际状态 | root、关节、安装/标定 revision、USD 传感器世界矩阵、可用 Fabric 当前矩阵、状态采样阶段 |
| 原生事件 | sensor_id、产品作用域、ReferenceTime、映射仿真时间、frameId（可空）、回调与 CPU 副本完成 monotonic 时间 |
| LiDAR 原生头 | GMO timestamp、frameStart/frameEnd 时间与位姿、坐标系、motion compensation 状态、offset 摘要及可用发射器/通道信息 |
| 相机 | CameraParams、渲染 view transform、分辨率、内参/畸变、原始通道与保存后的 RGB 布局 |
| 载荷 | 类型、shape、dtype、字节序、大小、SHA256、独立所有权、原始与派生路径 |
| 错误 | 来源映射失败、缺路、重复/冲突、非法载荷、状态缺失、保存失败、超限与不可观测原因 |
| 资源与阶段 | RSS/VRAM、队列组数/字节、落盘量、暂停/背压、启动/采样/排空/回读耗时 |

全部目标保存元数据、实际状态和正常取得的图像/XYZ。完整 GMO 采用预先固定的首/中/末及固定间隔索引，并在资源允许时保存异常邻域；异常触发的附加保存单列其耗时和采样偏倚。少量机制轮可在独立预算下保存所有完整 GMO。

原 GMO 字节和交给 SDK 解析器的副本分开。现有解析器会重定位指针字段，不能解析后再把修改过的字节当原始包。

## 7. 比较方法与共同门槛

### 7.1 先检查计数、回读和配对资格

按所有计划目标计算：每路载荷保存率、全路到齐率、来源可归属率、重复/冲突次数、超限次数、F 重放合格率和最终可比较率。不同拒绝原因可能重叠，报告集合交集，不能简单相加。

配对覆盖率以全计划目标为分母；配对误差以具有明确输入一致性和载荷来源的目标为分母。缺失目标不从总体成功率中删除。无法取得绝对几何的目标标 `unknown/not_observable`，不能算作几何通过。

独立回读检查真实 PNG/XYZ/ROS CDR 的尺寸、布局、有限值、标定、TF 和文件哈希。合法无返回的空点云单列；它不是天然失败，也不能在缺少可观测几何时参与位姿拟合。

### 7.2 原生时间与位姿

每侧分别检查原生事件时间相对该侧实际物理步的对应，保留原始差值。2ns 是当前时间转换与精确目标关联容差，不是允许跨帧补偿的窗口。

共同原生位姿参考门槛：平移欧氏误差不超过 1mm，旋转测地角不超过 1e-4rad。首先验证矩阵合法性、行列约定、单位和四元数顺序，旋转误差避免使用近单位矩阵下不稳定的直接 acos。

原 v06 的原有矩阵最大分量差门槛另列，不能与上述物理误差等同。两版都接受相同的独立检查；原代码通过不代表共同几何通过。

### 7.3 LiDAR 输出几何

在无噪声已知房间中，分别使用各侧实际状态将自有 XYZ 转到世界坐标，计算点到已知面距离，报告每组 P50/P95/P99、最大组 P95、有效点数和可观察方向。

初始理想几何门槛沿用每组点到面 P95 不超过 5mm，可观察旋转残差不超过 1e-4rad。水平 yaw 拟合只说明该方向，不代替六自由度或逐点时间验证。平面归属、50mm 歧义排除规则和小角度拟合范围预先冻结；不确定度不足以支持门槛判断时标 unknown。

两版点云不按数组行号盲目相减。若真实发射器/通道/回波身份可用，按其身份比较方向和距离；不可用时采用固定范围的几何距离、边缘及局部表面指标，并记录可观察性。仅靠最近邻或 ICP 配准后的残差不能证明同步正确。

在 scene18 保留原噪声，分别报告 C/F 差异与 F 的重复采集自然差异。理想房间的 5mm 门槛不直接移植为带噪正式场景的统一阈值。

### 7.4 相机输出

先检查内参、鱼眼投影模型、外参和渲染位姿。使用非对称已知标记测重投影，理想条件 P95 门槛为 1px；负对照必须能识别预定错步。

scene18 固定重点区域：铲齿、细杆、鱼眼边缘、遮挡显露、快速旋转和恢复首帧。输出同目标并排图、差分图、边缘偏移和必要的 PSNR/SSIM。ROI 由目标状态与预定规则产生，不能选看起来最接近的图片。

连续渲染与冻结 16+2 的历史不同，像素差可能来自降噪或抗锯齿；相似度分数不独立证明位姿同步。尚未预定像素相似度通过阈值时，报告数值和现象，不事后选一个能让结果通过的阈值。

### 7.5 统计与差异展示

每项列出有效分母、排除原因、P50/P95/P99、最大值、超限率、运行阶段和每次独立重复的结果。采用预先声明的 nearest-rank 分位数；既有工具使用不同算法时另行标明。

生成位姿/几何误差随物理步的曲线、原生误差与几何误差散点图、运动块差异表、误差与资源等待关系图、失败邻域连续样本及固定相机 ROI 图。

同一轮相邻样本存在相关性。置信区间优先以独立会话或运动块为单位，不能把大量连续样本视为独立重复。零失败只说明已覆盖范围；不据此宣称不存在稀有故障。

## 8. 根据采集结果选择机制实验

主配对实验完成后再选择下表中的干预。最小失败用例先复现，保留原始条件作为同轮参照。

| 观察结果 | 优先机制范围 | 下一项区分实验 |
|---|---|---|
| F 独立几何正确，C 错误；当前矩阵仍一致 | 动态渲染历史、端点选择或运动相关输出转换 | 低速纯旋转、反向/停留；按真实历史轨迹估计偏差 |
| 误差随角速度变化，等效时间稳定接近半步/一步 | 历史时间锚点或样本端点 | 60Hz/120Hz 对照及 tick 相位对照，分别控制速度和每步角增量 |
| 错误主要随每步小角度、初始朝向或旋转方向改变 | 旋转转换、精度或插值分支 | 角增量扫描、不同初始 yaw、float32/float64 离线计算对照 |
| 原生 frameEnd 位姿正确，XYZ 几何错误 | 实际检测或坐标输出/提取路径 | 独立解码原始 GMO 与提取器 XYZ；有条件时比较支持的 WORLD/SENSOR 输出 |
| 原始 GMO 独立转换正确，仅提取器 XYZ 错误 | 提取器或转换语义 | 固定同一个 GMO 包离线复算；核对原生端点与输出帧定义 |
| 原生头与 XYZ 同时偏移 | 上游取样或共享端点机制 | 查实际历史数据入口；版本对照与最小复现提交材料 |
| 单传感器通过，全组合失败 | 资源竞争、产品关联或完成窗口 | 逐级增加传感器，分离 GPU 渲染负载与 CPU 保存负载 |
| C 与 F 同时违反独立几何 | 共同 SDK/资产语义/坐标约定或分析器 | 静止已知几何、人工解析坐标及不同参考实现 |
| C 与 F 相近，但都没有独立几何证据 | 尚不能判定同步正确 | 增加已知标记/平面或最小场景，不把相近直接写成通过 |
| F 输入状态不同或目标被裁剪 | 重放与实验设计问题 | 修正映射并重做该配对轮，不归咎连续链路 |

恒速 yaw 段可报告等效时间差 `delta_t = delta_yaw / yaw_rate`，但它只是诊断量。在角速度接近零、反转或非匀速段，使用原始实际状态历史检验候选端点，不使用该除法，也不将拟合时间直接改写消息。

60Hz/120Hz 实验至少分为两类：保持角速度不变，观察每步增量与误差是否改变；保持每步角增量不变，通过相应角速度变化区分物理时间尺度。每个独立对照只改变其声明变量。

原始 GMO 独立转换需确认球坐标单位、发射器偏移、坐标系及输出 motion compensation 语义。缺少这些证据时，不因“另一个转换结果更接近”就认定提取器错误。必要通道只在新增机制配置中开启并记录额外负载。

当前关闭 Motion BVH 的组合已出现不支持警告，不能采纳为修复。新的 SDK、TLAS 或同步设置对照必须记录启动时有效值，不能仅引用配置请求。发现角增量相关现象也不能单凭公开 SLERP 头文件证明内部调用路径。

## 9. 资源、观测扰动与性能解释

E0 先实测每路 RGB/XYZ/GMO 大小、状态与日志量、写盘吞吐、RSS/VRAM 和 CPU 副本耗时，然后冻结整轮预算。四路 1920×1080 RGB 每个目标约 24.9MB 未压缩，点云和完整 GMO 另计；磁盘容量与在途内存分别估算。

保存链路采用有界队列、独立拥有的数组和明确的关闭/排空。只允许后台处理自有 CPU 数据，不在后台读取 USD、Kit 或已归还的 SDK 缓冲。队列满时在支持的安全边界暂停物理或终止实验并保留前缀，不能静默丢弃；这些暂停须记录，因为它们可能改变历史行为。

现有 `BoundedTrace` 的 128MiB 限制针对累计追踪输出，不代表 RAM。新增入口需要分别控制累计磁盘量、队列容量、历史缓存和整进程资源。不要沿用 120 秒总期限处理任意扩大后的实验。

详细诊断和普通产出测量分开。主效应比较尽量使用两侧相同的外部保存、哈希和元数据观测策略；实际 Kit 拓扑、原 v06 编码保存模块及额外观测成本如实记录。高频 Fabric 追踪和 profiler 放在有界机制轮，不能将其吞吐外推到普通运行。

第一轮 C→F 顺序适合来源配对，但具有时间顺序与缓存混杂，不直接用于性能因果结论。后续性能资格轮使用已冻结输入轨迹、各三轮交错执行、每轮额外 20 组预热加至少 200 组测量，并沿用现有质量与回读要求。纯产出、交互/预览负载、启动和排空分别记录；GUI/headless 条件及真实进程拓扑明确。

报告原始保存组吞吐与最终独立验证合格组吞吐。尚未覆盖完整正确性时，合格产能标 unknown；不能用回调频率或 GPU 利用率宣布速度通过。连续主路线至少两倍基线、控制延迟及 30 分钟全组合长测仍见原验收方案，不由本实验替代。

## 11. 实验交付与判定

每个阶段交付原始数据清单与哈希、实际条件、目标覆盖、输入配对资格、错误分类、逐组共同指标、图像/点云证据和可复现配置。报告至少包含：

```text
experiment_completed
raw_capture_integrity_ok
planned_target_coverage
pair_input_equivalence_ok
native_source_mapping_ok
native_pose_ok
independent_geometry_ok
image_quality_comparison
comparison_scope
mechanism_supported
mechanism_unresolved
next_discriminating_experiment
formal_continuous_acceptance
```

布尔结论采用 true/false/null，并提供传感器、运动段、重复轮次和证据路径。C 的观测结果优先完整呈现，F 的资格和重复性随后呈现，最后解释差异。未观察、不可配对、不可观察和实测失败分别说明。

判定逻辑如下：

- C/F 都通过输入资格和独立检查：可在已覆盖条件下报告连续效果符合要求，随后扩大模型和运行范围。
- F 合格而 C 失败：取得连续条件下的差异证据，进入最小机制干预，不停止于肉眼展示。
- F 不具备参考资格：保留 C 产出观察，重做参考或增加独立真值；不根据两版差异给单侧根因结论。
- 两版均失败：检查共同机制及分析器，避免以冻结链路默认正确。
- 数据或目标不完整：报告有效前缀与缺口，不能将其改写为完整实验。

只有后续真实连续录制、共同正确性、完整回读、生命周期和质量性能全部满足原验收契约，才更新正式连续验收状态。本方案完成或某轮实验保存成功不会自动更新该状态。
