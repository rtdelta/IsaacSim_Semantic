# 场景编辑与跨环境轨迹采集实现方案

日期：2026-10-19。状态：已实现并完成下述验收。实现版本：0.4.0。

## 目标与边界

允许编辑并保存场景后重新启动，不再人工登记整个场景文件的 SHA256。
同一条完成且排空的轨迹可在修改后的同路径场景或另一个兼容场景中采集。
轨迹文件不修改，任务单独记录来源、实际目标场景、资产身份和摆放变换。

沿用单台兼容挖机、统一节点命名和层级、原生零位、1×交互、逐帧离散位置与零物理速度。
更换场景必须完整重启流程；不实现运行中切换，不添加碰撞、受力或自动贴地。
不同零位、关节轴向或机械尺寸的自动轨迹重定向不在范围内。

## 两种采集用途

| 用途 | 目标场景 | 检查 |
| --- | --- | --- |
| 原场景复现 `original`（默认） | 轨迹保存的场景 | 原场景及已记录 USD 层的一致性、运动和传感器接口 |
| 更换环境采集 `environment` | 显式目标路径，同路径修改版也可 | 目标接口兼容性；原环境哈希变化不阻止任务 |

两者均保持轨迹完整性校验、完成状态、采样计划、关节限位和采集时钟核验。
跨环境任务不依赖原场景仍存在；旧轨迹信息不足时只接受已核验基线，证据不足报错。
原场景复现的一致性范围是已记录 USD 层，不宣称全部纹理/HDRI都被内容审计。

## 实现步骤

1. 解除场景路径和场景/挖机整文件哈希准入，将配置作为显式零位与运动接口约定。
   保留原哈希作为历史来源；新增已核验的关节连接、轴向、两侧关节框架和尺度检查。
2. 新轨迹保存组合后的运动及传感器兼容性描述，避免仅凭名称推断兼容。
   核验关节角色、父子刚体、轴向、零位、关节框架、参考变换、相机标定、雷达参数、安装参考。
3. 网页、命令行、采集任务统一传递 `scene_policy`、`target_scene`、目标 DomeLight 和摆放变换。
   创建私有轨迹快照后再次解析这些选项，避免原轨迹元数据覆盖目标路径。
4. 目标选择在启动前完成文件检查；在 Isaac 加载组合 Stage 后完成接口检查，正式写入前失败即退出。
   原场景模式保留 USD 哈希核验；环境模式检查兼容性描述，不检查原环境文件。
5. 摆放提供 `translation_m=[x,y,z]` 和 `yaw_deg`，默认零；使用主动刚体变换作用于整机位置和朝向。
   关节角、时间、采样计划、安装局部位姿保持源轨迹值；不缩放、不自动贴地和避障。
6. 输出实际目标场景 USD 清单、源轨迹身份、策略、兼容性结果与摆放参数。
   相机/雷达和 ROS TF 使用目标环境中的实际回读；源轨迹和源环境身份仍单独保留。
7. 更新操作指南和交付入口，运行单元回归、Linux 任务测试与短轨迹原生采集验证。

## 必须核验与无需一致的内容

必须核验：单位、坐标约定、唯一兼容挖机、四关节连接、轴向和零位、关节范围、
传感器 ID/类型/标定/安装参考、依赖可加载、完成轨迹完整性、有效采样网格和写入完整性。
环境模式无需与原场景一致：场景路径、环境几何、静态物体布局、材质、灯光以及环境 USD 哈希。
传感器安装随轨迹重放，目标 USD 中不同初始安装值不得悄然改变轨迹的观测位置。

## 验收标准

- 当前仅修改 Cube 的 scene18 可以启动、录制新轨迹并采集。
- 同一轨迹在原场景、修改后的同路径场景和不同路径场景采集成功；环境任务可在原环境缺失时运行。
- 原场景策略对资产变化明确失败；不兼容关节、零位、传感器在正式写入前失败并指出差异。
- 显式平移和旋转的根位置误差 ≤1e-5 m、姿态角误差 ≤1e-5 rad、关节角误差 ≤1e-4 rad。
- 组数、时间和写入数量符合采集计划，完整轨迹和指定组数、暂停/停止与排空不回退。
- 结果保留源轨迹与实际环境身份，源轨迹及源资产不被运行器改写。

## 执行与验证记录

已实现：接口准入、源/目标场景分离、原场景与更换环境两种策略、统一刚体摆放、
新轨迹接口记录、旧轨迹的已核验接口基线、网页与 CLI 输入、MCAP 和文件中的双重身份记录。

本地 62 项测试中 57 通过、5 项跳过（4 项 Linux 专用、1 项可选 FastAPI）；
test 的 Linux 62 项中 61 通过、1 项可选 FastAPI 跳过。网页 JavaScript 语法及 DOM 夹具通过，
本轮未重做 OS 键盘输入或真实浏览器视觉验收。

capture 实例完成原生轨迹录制，并使用真实 13 路雷达、4 路相机进行短采。
原场景、同路径修改版、不同路径目标且原场景缺失时的摆放采集，均完成 4 组及独立 MCAP 回读。
摆放采用平移 `[0.4,0.1,0.05] m`、绕世界 Z 轴 `15°`。
修改后原场景复现、错误关节轴和相机标定三项均按预期失败；接口错误未创建正式 bag。
旧轨迹跨环境完成 2 组采集与 MCAP 回读。7 个用例全部符合预期，4 次成功采集共 14 组，
最大根位置误差约 `5.32e-8 m`。详见 [验收摘要](../reports/acceptance_20261019/scene_replay_summary.json)。

初次隔离验证使用薄 sublayer 包装根层时触发原有 LiDAR 渲染位姿校验；原始 scene18 对照采集成功。
最终验收使用保留完整根层设置并绝对化引用的副本。未放宽任何传感器时钟或位姿阈值，
不宣称任意裸包装层都已验证兼容。另一次测试用 USDA 编辑串的换行语法错误已修正，失败尝试保留在运行报告中。

使用方式：完整重启后，网页“场景用途”选更换环境采集，填写目标路径与有效 DomeLight，
按需填写摆放变换；CLI 示例见 [换场景操作](../handoff/SceneSwitchGuide.md#9-同一轨迹在修改后的环境中采集)。
