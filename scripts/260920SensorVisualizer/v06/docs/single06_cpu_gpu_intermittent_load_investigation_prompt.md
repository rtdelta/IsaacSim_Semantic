# single06 CPU/GPU 间歇性高占用排查提示词

以下为提示词原文，可完整复制给执行 agent。

```text
你负责排查并验证 single06（原 v06）基于 Isaac Sim 运行时，CPU 与 GPU 交替、间歇性高占用及伴随卡顿的原因。目标是查明引擎执行机制和资源生命周期中的瓶颈，为后续机制改造提供证据。

1. 建立一组采集的因果时间线：姿态更新、场景同步、预热、渲染提交、GPU 执行、数据回读、编码写盘及资源回收。
2. 深入追踪 CPU 线程、Vulkan/RTX 队列、CUDA Stream、缓冲分配复用、外部内存交接及同步等待，重点验证重复预热和资源重建。
3. 优先复用现有 Nsight/NVTX；按组编号、阶段、进程和设备对齐日志。区分墙钟、线程 CPU 时间、GPU 执行时间及硬件活动，不能用整卡利用率直接推断瓶颈。
4. 使用独立实验入口做单变量对照，保持画质、传感器和轨迹一致；记录追踪开销。保留原代码，实验前备份，不修改系统环境。
5. 输出已证实原因、候选解释和证据缺口；提出可控的机制改造方向，说明接口边界、预期收益和验证办法。

验收以操作延迟、停顿长尾和完整采集耗时为准，不以占用率是否达到100%为准。
```
