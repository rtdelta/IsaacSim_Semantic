## 后续诊断与失败证据

5. 三轮 × 两条链路全部完成，共 18 组、234 份正式雷达点云。逐条以时间戳加 XYZ 哈希匹配 MCAP；相同时间戳多消息没有简单取首条。九个组配对中 135 个 mesh 的已记录世界矩阵、顶点、索引、有效可见性和 purpose 一致，`omni:sensor:*` 参数一致。
6. 原生 `native_dual` 首次双读诊断失败。现有 SDK 在空辅助数组后清除 AnnotatorCache，随后 CUDA 数组复制访问同一 cache 可抛 KeyError。只在实验探针中临时关闭该节点的数组复制标志、立即复制到自有 NumPy 内存并恢复标志；不更改 SDK 文件。成功重试在 `native_dual_retry1`，失败目录保留。
7. `legacy_raw` 首次探针已采到 GMO，但 Writer 所持 Annotator 原型没有显式绑定 node path，直接 get_node 抛错。该次正式采集本身通过，原始数组仍与正式数组一致。`legacy_raw_retry1` 给同一模板补充显式 observer，修复诊断读法；39 份双读全部一致。原始失败结果不改写。
8. 用户中断期间没有执行远端停进程。恢复连接后确认独立采集已经自然退出、无遗留进程、资产依赖哈希未变化，继续分析已有数据。
9. 通过安装目录读取官方 GMO parser、Annotator、Warp 的实际 API；未联网获取新库。GMO 仅从拥有内存的 ndarray 解析，不手工解引用未验证指针。当前 BASIC 输出没有 objectId，因此用独立三角形查询补充几何归属。
10. 从正式静止场景导出可见三角形，并用现有 Warp 进行最近表面和首个命中查询。分析核先通过已知平面的解析几何验证。该核不模拟 RTX 材质、透明度、传感器有效回波筛选；Cube/Plane 分析基元未纳入导出，报告限定其结论范围。
