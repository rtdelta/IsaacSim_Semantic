## Project & Stage 导入修复

首次人工导入暴露了两项确定问题：空 `stage.usd_path` 的项目可以保存但无法再次加载；FilePicker 在双击事件回调内部同步 `destroy()`，Kit 报告 `Container::destroy was called during an event or draw`。

修复后：

- 新项目通过严格 Schema 构造，空 USD 不会进入可编辑状态；
- Repository 在创建目录或写入 revision 之前执行与加载端相同的 Schema 验证；
- Studio 检查 `.swproject` 后缀、绝对项目路径、USD 后缀和本地 USD 存在性；
- 新项目不能覆盖已有 manifest，已有项目必须使用 Open；
- FilePicker 先隐藏，并在下一次 Kit update 中销毁和交付选择回调；
- 项目文件夹选择、保存、重新导入和 USD 自动加载由专用 Kit 探针覆盖。
