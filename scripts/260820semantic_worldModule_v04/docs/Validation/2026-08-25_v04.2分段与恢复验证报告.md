## 11. 当前结论

已经得到以下证据：

1. `segment_frames` 真实对应独立 Isaac 进程，而不是同一 Runtime 内的逻辑循环。
2. Realtime 和 Path Tracing 均能跨 Segment 完成 RGB、semantic ID 和 semantic color 输出。
3. Ledger 是恢复事实来源；停止/恢复不会覆盖已提交产物。
4. Worker 非正常退出会得到 failed 状态和结构化失败报告，不会静默终止或误报完成。
5. GPU、进度、Segment timing、心跳和 ETA 均能持久化并被 Studio/CLI 读取。
6. 100 帧和 300 帧两档 720p Path Tracing 已稳定通过。
7. 1000 帧 720p Path Tracing 最终档位已稳定通过。
8. CSV articulation 的绝对 seek 能跨 3 个独立 Worker 正确恢复段起点。
9. 最终核对的 9 个功能、故障与长跑 Job 全部为 `completed`，capture group 与 Segment 进度均达到总数。
10. 最终没有残留的 v04 Job Runner 或 Segment Worker；数据盘仍有约 59 GiB 可用空间。

v04.2 的核心实现、故障恢复与阶段长跑验收已经完成。更高生产 SPP、更多传感器和不同动力学任务仍应针对各自项目另做性能与物理正确性验收。
