## 已定位并修复的问题

- 错误 `libpython` 会在 async engine 启动时原生崩溃：已由 v04 wrapper 和 host preflight 双重阻止。
- 变体切换时删除匿名 Session sublayer 可能触发 USD NULL weak pointer：改为 Stage 生命周期内持有同一 layer，仅清空内容。
- Supervisor 进度原先按变体计数：改为按 enabled sensor × variant × frame 的原子采集组计数。
- 语义-only 变体原先可能经过 RGB 分支：现在 Camera driver 不读取 RGB，Coordinator 也只编码请求模态。
- 相机覆盖原先只存在于 JobSpec，未真正作用于 USD Camera：现在由 SensorPlugin 写匿名 Session Layer，Driver 回读有效值并写入任务/帧级审计信息。
- Camera `Gf.Matrix4d` 原先可能退化为不可复用字符串：现在固化 4×4 数值局部矩阵，并单独记录组合后的世界矩阵。
