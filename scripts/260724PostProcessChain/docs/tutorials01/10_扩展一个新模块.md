# 10 扩展一个新模块

本章以“对所有可见合格斗齿框求总外包框”为例，展示一个内置模块从配置到注册、测试和接入的完整路径。

示例模块名：

```text
all_visible_teeth_yolo
```

它与当前 `tooth_group_yolo` 的区别：

- 当前模块只用两个端点框；
- 新模块使用所有可见且达到阈值的上游框。

以下代码是教学骨架。真正提交前仍应根据业务增加 label 过滤和更完整测试。

## 1. 新模块目录

```text
postprocess_chain/modules/all_visible_teeth_yolo/
├─ __init__.py
├─ module.py
├─ module_config.py
├─ all_visible_teeth_yolo.json
├─ README.md
└─ tests/
   ├─ __init__.py
   └─ test_all_visible_teeth_yolo.py
```

保持与现有模块一致，未来维护者能快速找到配置、实现和测试。

## 2. 先定义业务契约

配置：

```json
{
  "schema_version": 1,
  "source_artifact": "tooth_boxes.semantic_boxes",
  "output": {
    "directory": "modules/all_visible_teeth",
    "layout": "flat_yolo"
  },
  "class": {
    "yolo_id": 0,
    "yolo_name": "visible_teeth_group"
  },
  "min_pixels": 10,
  "missing_policy": "exclude_frame"
}
```

先明确：

- 输入 artifact 类型为 `SemanticBoxSet`；
- 至少一个合格框即可输出；
- 输出单类别 ID 0；
- 没有合格框时可排除、写空标签或报错；
- 成功时发布局部 artifact `group_box`。

## 3. 配置 dataclass

`module_config.py`：

```python
from __future__ import annotations

from dataclasses import dataclass

from ...common.config_io import (
    load_json_object,
    optional_integer,
    optional_string,
    parse_module_output,
    reject_unknown_fields,
    require_integer,
    require_object,
    require_string,
)
from ...common.models import ModuleOutputConfig
from ...pipeline.module_base import RunContext
from ...pipeline.orchestrator_config import ModuleSpec


@dataclass(frozen=True)
class AllVisibleTeethConfig:
    source_artifact: str
    output: ModuleOutputConfig
    yolo_id: int
    yolo_name: str
    min_pixels: int
    missing_policy: str


def load_module_config(
    spec: ModuleSpec,
    run_context: RunContext,
) -> AllVisibleTeethConfig:
    raw = load_json_object(spec.config_path, f"module {spec.module_id}")
    context = f"module {spec.module_id}"
    reject_unknown_fields(
        raw,
        {
            "schema_version",
            "source_artifact",
            "output",
            "class",
            "min_pixels",
            "missing_policy",
        },
        context,
    )
    if raw.get("schema_version") != 1:
        raise ValueError(f"{context}.schema_version must be 1")

    output = parse_module_output(
        require_object(raw, "output", context),
        f"{context}.output",
        run_context.output_root,
    )
    class_raw = require_object(raw, "class", context)
    reject_unknown_fields(
        class_raw,
        {"yolo_id", "yolo_name"},
        f"{context}.class",
    )
    yolo_id = require_integer(
        class_raw,
        "yolo_id",
        f"{context}.class",
        minimum=0,
    )
    if yolo_id != 0:
        raise ValueError(f"{context}.class.yolo_id must be 0")

    missing_policy = optional_string(
        raw,
        "missing_policy",
        "exclude_frame",
        context,
    )
    if missing_policy not in {"exclude_frame", "empty_label", "error"}:
        raise ValueError(
            f"{context}.missing_policy must be "
            "exclude_frame, empty_label, or error"
        )

    return AllVisibleTeethConfig(
        source_artifact=require_string(raw, "source_artifact", context),
        output=output,
        yolo_id=yolo_id,
        yolo_name=require_string(
            class_raw,
            "yolo_name",
            f"{context}.class",
        ),
        min_pixels=optional_integer(
            raw,
            "min_pixels",
            10,
            context,
            minimum=1,
        ),
        missing_policy=missing_policy,
    )
```

要点：

- `reject_unknown_fields` 防止拼写错误被忽略；
- dataclass 冻结，模块配置不可变；
- 输出路径复用 `parse_module_output`，防止逃逸 `output_root`；
- 运行开始时完成所有可静态验证的约束。

## 4. 模块实现

`module.py`：

```python
from __future__ import annotations

from ...common.models import (
    ModuleResult,
    PixelBox,
    SemanticBoxSet,
    YoloAnnotationSet,
    YoloDetection,
)
from ...pipeline.frame_context import FrameArtifactStore, FrameContext
from ...pipeline.module_base import PipelineModule, RunContext
from ...pipeline.module_registry import register_module
from ...pipeline.orchestrator_config import ModuleSpec
from .module_config import AllVisibleTeethConfig, load_module_config


@register_module("all_visible_teeth_yolo")
class AllVisibleTeethYoloModule(PipelineModule):
    def __init__(
        self,
        spec: ModuleSpec,
        config: AllVisibleTeethConfig,
    ) -> None:
        super().__init__(
            module_id=spec.module_id,
            depends_on=spec.depends_on,
            output_dir=config.output.directory,
            class_names=(config.yolo_name,),
        )
        self.config = config

    @classmethod
    def from_config(
        cls,
        spec: ModuleSpec,
        run_context: RunContext,
    ) -> "AllVisibleTeethYoloModule":
        return cls(spec, load_module_config(spec, run_context))

    def validate(self, run_context: RunContext) -> None:
        super().validate(run_context)
        source_module_id, separator, artifact_name = (
            self.config.source_artifact.partition(".")
        )
        if not separator or not source_module_id or not artifact_name:
            raise ValueError(
                f"module {self.module_id!r} source_artifact must be "
                "'<module_id>.<artifact_name>'"
            )
        if source_module_id not in self.depends_on:
            raise ValueError(
                f"module {self.module_id!r} must depend on "
                f"{source_module_id!r}"
            )

    def _missing_result(self) -> ModuleResult:
        if self.config.missing_policy == "exclude_frame":
            return ModuleResult(
                disposition="exclude",
                metrics={"missing_boxes": 1},
            )
        if self.config.missing_policy == "empty_label":
            return ModuleResult(
                annotation=YoloAnnotationSet(()),
                metrics={"missing_boxes": 1},
            )
        raise ValueError("no eligible semantic boxes")

    def process_frame(
        self,
        frame: FrameContext,
        artifacts: FrameArtifactStore,
    ) -> ModuleResult:
        del frame
        source = artifacts.get(self.config.source_artifact)
        if not isinstance(source, SemanticBoxSet):
            raise TypeError(
                f"artifact {self.config.source_artifact!r} "
                "must be SemanticBoxSet"
            )

        eligible = tuple(
            item
            for item in source.boxes
            if item.pixel_count >= self.config.min_pixels
        )
        if not eligible:
            return self._missing_result()

        group_box = PixelBox(
            left=min(item.box.left for item in eligible),
            top=min(item.box.top for item in eligible),
            right=max(item.box.right for item in eligible),
            bottom=max(item.box.bottom for item in eligible),
        )
        detection = YoloDetection(
            class_id=self.config.yolo_id,
            class_name=self.config.yolo_name,
            box=group_box,
        )
        return ModuleResult(
            artifacts={"group_box": group_box},
            annotation=YoloAnnotationSet((detection,)),
            metrics={
                "missing_boxes": 0,
                "source_boxes": len(eligible),
            },
        )
```

## 5. 模块包入口

新目录的 `__init__.py`：

```python
"""Generate one envelope box from all eligible semantic boxes."""

from .module import AllVisibleTeethYoloModule

__all__ = ["AllVisibleTeethYoloModule"]
```

还必须修改总的 `postprocess_chain/modules/__init__.py`：

```python
from .all_visible_teeth_yolo.module import AllVisibleTeethYoloModule
from .semantic_yolo_boxes.module import SemanticYoloBoxesModule
from .tooth_group_yolo.module import ToothGroupYoloModule

__all__ = [
    "AllVisibleTeethYoloModule",
    "SemanticYoloBoxesModule",
    "ToothGroupYoloModule",
]
```

缺少这一步时，装饰器不会执行，总配置会报 unknown module type。

## 6. 接入总配置

```json
{
  "id": "all_visible_teeth",
  "type": "all_visible_teeth_yolo",
  "enabled": true,
  "config": "../postprocess_chain/modules/all_visible_teeth_yolo/all_visible_teeth_yolo.json",
  "depends_on": ["tooth_boxes"]
}
```

三模块依赖可写成并行分支：

```text
                  ┌─> tooth_group
tooth_boxes ──────┤
                  └─> all_visible_teeth
```

同一帧内两个下游仍顺序执行，但二者互不依赖，并分别消费同一上游 artifact。

## 7. 单元测试骨架

至少测试总外包确实覆盖中间高齿：

```python
def test_envelope_uses_all_visible_boxes(self):
    artifacts = FrameArtifactStore()
    artifacts.publish(
        "tooth_boxes",
        {
            "semantic_boxes": SemanticBoxSet(
                (
                    SemanticBox("tooth_1", 1, 20, PixelBox(10, 20, 15, 40)),
                    SemanticBox("tooth_3", 3, 20, PixelBox(20, 5, 25, 30)),
                    SemanticBox("tooth_5", 5, 20, PixelBox(30, 12, 39, 35)),
                )
            )
        },
    )
    result = module.process_frame(frame, artifacts)
    self.assertEqual(
        result.annotation.detections[0].box,
        PixelBox(10, 5, 39, 40),
    )
```

还要覆盖：

- 没有合格框时三种 policy；
- 小框过滤；
- artifact 类型错误；
- `source_artifact` 与 `depends_on` 不一致；
- 输出 class ID/name；
- `workers=2` 的集成运行。

## 8. 扩展模块的设计守则

### 保持模块可 pickle

模块实例会传给 worker。只保存配置 dataclass、字符串、数字、Path 等简单对象。资源在
`process_frame` 内短时打开，或设计明确的 worker 初始化策略。

### 不直接导入业务模块

共享数据类型放到 `common.models`，帧内值通过 artifact 传递。不要从
`semantic_yolo_boxes.module` 调其私有函数来形成隐式依赖。

### artifact 使用命名空间

发布局部名：

```python
{"group_box": group_box}
```

不要发布：

```python
{"all_visible_teeth.group_box": group_box}
```

命名空间由 store 自动添加。

### 区分 annotation 的三态

- 普通 annotation：写正样本；
- 空 annotation：写负样本；
- `None`：成功但本模块不输出标签；
- exclude：整个样本不进入该模块数据集。

### 输出 detection 与 classes 一致

每个 detection 的 ID/name 必须与 `class_names` 对应，否则写出阶段失败。

### 配置变化要可审计

业务阈值、选择策略和输出类别都应进入模块 JSON，而不是硬编码。模块配置内容会进入运行指纹。

## 9. 新模块完成定义

只有同时满足以下条件才算完成：

```text
[ ] 有明确输入、输出、缺失语义
[ ] 有严格模块配置和默认示例
[ ] 有唯一 type 注册名
[ ] 已加入 modules/__init__.py
[ ] 不与其他模块共享输出目录
[ ] artifact 有文档和类型检查
[ ] 单元测试覆盖正常与边界
[ ] 端到端 workers=1 通过
[ ] 端到端 workers=2 通过
[ ] README 说明算法不是/是什么
[ ] 全部原有测试仍通过
```
