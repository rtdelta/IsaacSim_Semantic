# 260724PostProcessChain 从零到掌握

这是一套与当前源码同步的学习笔记，适用于第一次接触本项目的人，也可作为后续修改配置、排查数据、扩展模块时的工作手册。

文档基于 2026-07-24 的项目实现编写。学习时请把
`scripts/260724PostProcessChain` 当作“项目根目录”，所有命令默认从该目录执行。

## 学完后应该能做到什么

完成整套学习后，你应该能够：

- 说清 RGB、semantic ID、semantic mapping 和 YOLO 标签之间的关系；
- 独立准备输入数据并配置、运行当前两级后处理链；
- 理解配置校验、帧发现、拓扑排序、帧级多进程和中间产物机制；
- 准确解释两个内置模块的算法、阈值和缺失帧策略；
- 根据 `manifest.json`、`summary.json` 和 `errors.jsonl` 判断一次运行是否可信；
- 安全地断点续跑、覆盖旧结果和调节并行度；
- 编写、注册、测试一个新的流水线模块；
- 用当前工作区中的真实 Fangshan 数据完成一次端到端处理。

## 项目一句话模型

```text
成对的 RGB + semantic_id.npy
              │
              ▼
semantic_yolo_boxes
  ├─ 每个配置 semantic label 的整图外包框
  └─ 帧内中间产物 SemanticBoxSet
              │
              ▼
tooth_group_yolo
  └─ 两个端部斗齿框的外包集合框
              │
              ▼
每个模块各自的 YOLO 图片、标签和 classes.txt
```

流水线的并行单位是“帧”。同一帧内的模块按依赖顺序执行；不同帧可以由多个进程并行处理。

## 阅读约定

- `PROJECT_ROOT`：`scripts/260724PostProcessChain`。
- `WORKSPACE_ROOT`：包含 `scripts` 和 `output` 的 `260707IsaacSIm` 目录。
- 示例命令以 Windows PowerShell 为主。
- JSON 中的相对路径不是相对终端当前目录，而是相对“包含该 JSON 的目录”。
- 像素框统一使用半开区间 `[left, top, right, bottom)`。
- “semantic label”表示 mapping 中的语义名称；“YOLO class”表示训练数据中的类别，两者不一定一一对应。

## 最终掌握标准

在不照抄文档的情况下完成以下任务，即可认为已经掌握当前项目：

1. 为一份新的 semantic 数据集写出总配置和两个模块配置；
2. 解释为何 mapping 标签必须与模块标签逐字匹配；
3. 手算一个像素框对应的 YOLO 归一化行；
4. 解释空标签、排除帧和错误帧的区别；
5. 从一条 `errors.jsonl` 记录定位到加载、计算或写出阶段；
6. 解释为什么断点续跑时上游仍需重新计算中间产物；
7. 新增一个能在 `workers=2` 下运行并有单元测试的模块。
