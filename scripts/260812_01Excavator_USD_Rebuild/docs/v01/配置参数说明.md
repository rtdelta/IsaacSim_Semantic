# 配置参数说明

本文逐项说明 `build_config.template.json` 和 `joint_calibration.template.json` 的字段含义。模板是标准 JSON，不使用注释；所有解释集中在本文。

## 1. 通用数据约定

| 约定 | 含义 |
|---|---|
| `id` | 配置内部稳定 ID，用于对象间引用；同一对象类型内必须唯一 |
| `enabled` | 是否启用当前对象；禁用对象不参与正式构建和启用数量统计 |
| `*_m` | 单位为米 |
| `*_deg` | 单位为度 |
| `*_deg_s` | 单位为度每秒 |
| `*_wxyz` | 四元数顺序为 `[w,x,y,z]` |
| 绝对 Prim 路径 | 以 `/` 开头，例如 `/Excavator` |
| 相对 Prim 路径 | 不以 `/` 开头，拼接到所属根 Prim 或 Link Prim 后 |
| `null` 覆盖值 | 继承相应 defaults 或 profile 中的值 |
| `null` 阈值或期望数量 | 不启用该项限制 |
| `null` 必需测量值 | 表示尚未提供，正式构建必须失败 |

## 2. 主构建配置

### 2.1 `schema_version`

配置协议版本。构建器必须先检查兼容性，不得用未知版本继续构建。本模板使用 `1.0`。

### 2.2 `project`

| 参数 | 类型 | 含义 |
|---|---|---|
| `asset_id` | string | 机器可读资产 ID，用于日志、报告、输出元数据和缓存标识 |
| `asset_name` | string | 用户可读资产名称 |
| `description` | string | 资产来源和用途说明 |

### 2.3 `paths`

| 参数 | 类型 | 含义 |
|---|---|---|
| `relative_path_base` | enum | 相对路径解析基准；v01 支持 `config_directory` |
| `expand_environment_variables` | bool | 是否先展开路径中的环境变量 |
| `joint_calibration_file` | path | 关节标定文件路径 |
| `mesh_component_assignment_file` | path/null | 可选的 Mesh 连通分量归属文件；Fangshan 使用一次性迁移固化的精确归属，正常构建会校验源 SHA-256 和分量指纹 |
| `output_directory` | path | 所有生成文件的输出根目录 |

当 `relative_path_base=config_directory` 时，路径相对于实际使用的主配置文件所在目录，而不是相对于脚本目录或当前工作目录。

### 2.4 `stage`

| 参数 | 类型 | 含义 |
|---|---|---|
| `root_prim_path` | absolute prim path | 新挖掘机模型的根 Prim |
| `default_prim_path` | absolute prim path | 输出 Stage 的 Default Prim，一般等于根 Prim |
| `up_axis` | `X`/`Y`/`Z` | 输出 Stage 的上方向；Isaac Sim 目标方案使用 `Z` |
| `meters_per_unit` | positive number | 输出 Stage 一个数值单位对应的米数，推荐 `1.0` |
| `model_kind` | string | USD Model Kind；可复用整机资产使用 `component` |

### 2.5 `coordinates`

#### `bake_transform_into_geometry`

为 `true` 时，公共转正和平移会烘焙进 3DGS position/orientation、Mesh 顶点和关节中心/轴，Link 初始 Xform 可以保持统一。为 `false` 时由上层 Xform 表达 Gaussian 公共变换，Mesh 和 Joint 仍输出到同一目标坐标；Fangshan v01 正式配置使用 `false`，以确保 Gaussian 的局部 position、orientation 和球谐属性原样保留。

#### `origin`

| 参数 | 类型 | 含义 |
|---|---|---|
| `mode` | enum | 原点计算方法；`obb_center` 表示引用几何的有向包围盒中心 |
| `reference` | object reference | 计算原点所用的 Gaussian、Mesh 或 Link |
| `offset_m` | vec3 | 在计算结果上附加的米制偏移 |

本项目默认引用履带 Gaussian，并把履带 OBB 几何中心作为整机原点。

#### `orientation`

| 参数 | 类型 | 含义 |
|---|---|---|
| `mode` | enum | `landmark_pca` 自动估计；`explicit_matrix` 使用显式旋转矩阵 |
| `pca_reference` | object reference | 用于 PCA 估计主方向的几何 |
| `forward_from` | object reference | 前向判定向量的起点对象 |
| `forward_to` | object reference | 前向判定向量的终点对象 |
| `up_positive_references` | array | 用于确定 PCA 上方向正负的参考对象 |
| `target_axes.forward` | signed axis | 挖掘机前方要对齐的目标轴，默认 `+X` |
| `target_axes.up` | signed axis | 挖掘机上方要对齐的目标轴，默认 `+Z` |
| `target_axes.lateral` | signed axis | 侧向目标轴，默认 `+Y` |
| `explicit_rotation_matrix` | 3×3/null | `explicit_matrix` 模式使用的正交旋转矩阵 |
| `post_rotation_deg_xyz` | vec3 | 主转正完成后附加的 XYZ 欧拉角修正 |

合法 signed axis 为 `+X`、`-X`、`+Y`、`-Y`、`+Z`、`-Z`。三个目标轴必须相互正交并构成构建器要求的右手坐标系。

#### 对象引用格式

```json
{
  "reference_type": "gaussian_part",
  "reference_id": "track_gaussian"
}
```

坐标计算中的 `reference_type` 支持：

| 值 | 解析对象 |
|---|---|
| `gaussian_part` | `gaussian.parts[]` 中相同 ID 的启用部件 |
| `mesh_part` | `mesh.parts[]` 中相同 ID 的启用部件 |
| `link` | 该 Link 下所有启用的构建几何；构建器必须记录实际使用了哪些部件 |

### 2.6 `gaussian`

| 参数 | 类型 | 含义 |
|---|---|---|
| `enabled` | bool | 3DGS 子系统总开关 |
| `defaults` | object | 全部 Gaussian 部件的默认导入设置 |
| `parts` | array | 任意数量的 3DGS 部件 |

#### `gaussian.defaults`

| 参数 | 类型 | 含义 |
|---|---|---|
| `source_format` | enum | 输入格式；当前使用 `gaussian_splat_ply` |
| `units_to_meters` | positive number | PLY 数值乘以该比例后转换成米 |
| `visibility` | token | USD 默认可见性，通常为 `inherited` |
| `purpose` | token | USD purpose，3DGS 通常为 `default` |
| `preserve_all_attributes` | bool | 保留 SH、opacity、scale、rotation 等 Gaussian 属性 |
| `sh_degree` | `auto`/integer | `auto` 根据 PLY 属性推断，或显式设置 SH 阶数 |
| `quaternion_order` | enum | 输入 PLY 四元数的分量顺序，例如 `wxyz` |
| `semantic_enabled` | bool | 新部件未覆盖时的默认语义开关 |
| `semantic_type` | string | 默认语义类型，例如 `class` |

#### `gaussian.parts[]`

| 参数 | 类型 | 含义 |
|---|---|---|
| `id` | string | Gaussian 部件唯一 ID |
| `enabled` | bool | 是否构建此部件 |
| `source_file` | path | 3DGS PLY 文件路径 |
| `link_id` | string | 该部件归属的 Link ID；决定其随哪个刚体运动 |
| `relative_prim_path` | relative prim path | 在所属 Link Prim 下的输出路径 |
| `units_to_meters_override` | number/null | 覆盖默认单位比例；`null` 表示继承 |
| `visibility_override` | token/null | 覆盖默认可见性 |
| `semantic.enabled` | bool | 是否为此部件添加语义 |
| `semantic.label` | string | 语义标签内容 |
| `semantic.type` | string | 当前部件的语义类型 |

3DGS 数量等于启用的 `parts` 元素数量，不要求固定为 15。增加或删除部件不应修改 Python 源码。

### 2.7 `mesh`

| 参数 | 类型 | 含义 |
|---|---|---|
| `enabled` | bool | Mesh 子系统总开关 |
| `defaults` | object | 所有输出 Mesh 的默认策略 |
| `sources` | array | 一个或多个源 Mesh 文件定义 |
| `parts` | array | 拆分或复制后形成的逻辑 Mesh 部件 |

#### `mesh.defaults`

| 参数 | 类型 | 含义 |
|---|---|---|
| `visibility` | token | 默认 `invisible`，防止与 3DGS 重叠 |
| `purpose` | token | 默认 `proxy`，表示代理/辅助几何 |
| `material_policy` | enum | `preserve` 表示尽量保留源材质和 Primvar |
| `create_collision` | bool | 是否从输出 Mesh 创建碰撞几何 |

#### `mesh.sources[]`

| 参数 | 类型 | 含义 |
|---|---|---|
| `id` | string | 源 Mesh 定义唯一 ID |
| `enabled` | bool | 是否读取该源 |
| `source_file` | path | 源 USD 路径 |
| `source_prim_path` | absolute prim path | 源 Stage 中真正包含拓扑的 Mesh Prim |
| `source_format` | enum | 输入格式；当前为 `usd_mesh` |
| `units_to_meters` | positive number | Mesh 数值到米的换算比例；必须显式设置，不能只信源 Stage 元数据 |

#### `mesh.sources[].split`

| 参数 | 类型 | 含义 |
|---|---|---|
| `enabled` | bool | 是否把一个源 Mesh 拆为多个逻辑部件 |
| `mode` | enum | `connected_components_with_gaussian_reference` 表示先求连通分量，再用 Gaussian 参考分类 |
| `assignment_method` | enum | `nearest_reference_cloud` 使用到参考点云的距离分类 |
| `distance_metric` | enum | 距离度量，当前为 `euclidean` |
| `preserve_connected_components` | bool | 禁止将同一连通分量拆到多个 Link |
| `preserve_topology` | bool | 保证输出面、索引和相关 Primvar 一致重映射 |
| `fail_on_unassigned_component` | bool | 存在无法分配的连通分量时是否失败 |
| `fail_on_ambiguous_component` | bool | 第一和第二候选过于接近时是否失败 |
| `ambiguity_margin_m` | nonnegative number | 候选间小于该米制差值时判为歧义 |

#### `mesh.parts[]`

| 参数 | 类型 | 含义 |
|---|---|---|
| `id` | string | 输出逻辑 Mesh 部件唯一 ID |
| `enabled` | bool | 是否生成该部件 |
| `source_id` | string | 对应 `mesh.sources[]` 中的源 ID |
| `link_id` | string | 此 Mesh 所属刚体 Link ID |
| `relative_prim_path` | relative prim path | Mesh 在 Link 下的输出路径 |
| `reference_gaussian_part_ids` | string array | 用于判断源连通分量归属的一个或多个 Gaussian ID |
| `visibility_override` | token/null | 覆盖 Mesh 默认可见性 |
| `purpose_override` | token/null | 覆盖 Mesh 默认 purpose |
| `create_collision_override` | bool/null | 覆盖默认碰撞开关 |

一个 Link 可以包含多个 Mesh，一个 Mesh 也可以用多个 Gaussian 作为分类参考。例如铲斗 Mesh 可以同时参考斗体和多个斗齿 Gaussian。

### 2.8 `physics_profiles`

`physics_profiles` 是以名称为键的可复用 Link 物理模板。`capture_placeholder` 表示为了采集项目和 articulation 初始化设置的占位值，不代表真实质量特性。

| 参数 | 类型 | 含义 |
|---|---|---|
| `rigid_body_enabled` | bool | 是否应用并启用 RigidBodyAPI |
| `kinematic_enabled` | bool | 是否为运动学刚体；浮动 articulation 使用 `false` |
| `disable_gravity` | bool | 是否对 Link 关闭重力 |
| `mass` | positive number | 占位或真实质量 |
| `center_of_mass` | vec3 | Link 局部坐标中的重心 |
| `diagonal_inertia` | positive vec3 | 对角惯量，三个分量均必须大于零 |
| `principal_axes_wxyz` | quaternion | 主惯量坐标系旋转 |
| `linear_damping` | number/null | 线性阻尼；`null` 表示不显式写入 |
| `angular_damping` | number/null | 角阻尼 |
| `solver_position_iteration_count` | integer/null | PhysX 位置求解迭代次数 |
| `solver_velocity_iteration_count` | integer/null | PhysX 速度求解迭代次数 |

### 2.9 `links[]`

| 参数 | 类型 | 含义 |
|---|---|---|
| `id` | string | Link 唯一 ID，是 Gaussian、Mesh 和 Joint 的关联中心 |
| `enabled` | bool | 是否生成此刚体 Link |
| `display_name` | string | UI 可读名称 |
| `prim_path` | relative prim path | 相对 `root_prim_path` 的 Link 路径 |
| `physics_profile` | string | 使用的 `physics_profiles` 键名 |
| `physics_overrides` | object | 覆盖所选物理模板中的个别字段 |

例如只覆盖某个 Link 的质量：

```json
{
  "physics_profile": "capture_placeholder",
  "physics_overrides": {
    "mass": 2.0
  }
}
```

Link 数量由数组决定，不固定为五个。

### 2.10 `articulation`

| 参数 | 类型 | 含义 |
|---|---|---|
| `enabled` | bool | 是否构建 articulation |
| `mode` | enum | `floating` 或 `fixed` |
| `articulation_root` | body/link reference | articulation 根刚体引用 |
| `api_placement` | enum | `root_body` 表示将 ArticulationRootAPI 放到根刚体 |
| `enabled_self_collisions` | bool | 是否允许 articulation Link 之间自碰撞 |

#### `fixed_base`

| 参数 | 类型 | 含义 |
|---|---|---|
| `enabled` | bool | 是否生成世界固定关节 |
| `joint_prim_path` | relative prim path | 世界固定关节输出路径 |
| `body` | body reference | 固定到世界的刚体 |

本项目首版使用 `mode=floating` 且 `fixed_base.enabled=false`。若以后使用 fixed，校验器应要求两项相互一致。

### 2.11 `joints[]`

Joint 数量由数组长度决定。

| 参数 | 类型 | 含义 |
|---|---|---|
| `id` | string | Joint 唯一 ID |
| `enabled` | bool | 是否生成此 Joint |
| `display_name` | string | UI 可读名称 |
| `type` | enum | v01 目标类型为 `revolute` |
| `prim_path` | relative prim path | 相对根 Prim 的 Joint 路径 |
| `body0` | body reference | 父侧刚体引用 |
| `body1` | body reference | 子侧刚体引用 |
| `geometry` | object | 中心、轴及其来源 |
| `limits` | object | 角度限位 |
| `initial_position_deg` | number | 构建零位对应的初始角度 |
| `collision_enabled` | bool | 是否允许该 Joint 两端刚体互相碰撞 |
| `drive` | object | 可选角度 Drive 设置 |

#### `body0`、`body1` 与固定端 body

```json
{
  "reference_type": "link",
  "reference_id": "boom",
  "prim_path": null
}
```

| `reference_type` | 使用字段 | 含义 |
|---|---|---|
| `link` | `reference_id` | 直接解析到对应带 RigidBodyAPI 的 Link Xform；Fangshan 正式配置推荐且使用此形式 |
| `mesh_part` | `reference_id` | 找到 Mesh，再解析其 `link_id`；仅作为通用兼容形式，最终仍必须解析到 Link Xform |
| `prim_path` | `prim_path` | 指向配置外的绝对刚体 Prim；属于高级模式 |
| `world` | 无 | 世界端，只用于允许世界端的 Joint 类型 |

无论使用哪种引用，最终 USD Joint 都不指向可视 Mesh Prim。Fangshan 直接解析示例：

```text
body1 = link:boom
→ links[boom].prim_path = Links/boom
→ /Excavator/Links/boom
→ physics:body0 或 physics:body1
```

目标 `/Excavator/Links/boom` 应是 Xform，并应用 `RigidBodyAPI`。Mesh 和 Gaussian 只是该 Link 下的视觉子 Prim。关节标定中的 `source_mesh_part_ids` 用于几何验证，不参与 Fangshan body 解析。

#### `geometry`

| 参数 | 类型 | 含义 |
|---|---|---|
| `source` | enum | `calibration_file` 从标定文件读；`explicit` 使用 override |
| `calibration_id` | string/null | 对应标定文件中的 Joint ID |
| `coordinate_frame` | string | 中心和轴所属源坐标系名称 |
| `center_override` | vec3/null | 非空时覆盖标定中心 |
| `axis_override` | vec3/null | 非空时覆盖标定轴 |
| `axis_sign` | `1`/`-1` | 保持或翻转关节轴，同时定义关节角正方向 |

`source=explicit` 时，`center_override` 和 `axis_override` 都必须非空。`source=calibration_file` 时允许用任意一个 override 覆盖对应标定值，但报告必须记录最终来源。

#### `limits`

| 参数 | 类型 | 含义 |
|---|---|---|
| `enabled` | bool | 是否写入角度限位 |
| `lower_deg` | finite number | 最小角度 |
| `upper_deg` | finite number | 最大角度，必须大于等于最小角度 |

限位不能由圆弧几何唯一推断，必须由旧资产、机械资料或人工确认后填写。

#### `drive`

| 参数 | 类型 | 含义 |
|---|---|---|
| `enabled` | bool | 是否创建 Angular Drive；当前直接关节位置采集使用 `false` |
| `type` | enum | `force` 或 `acceleration` |
| `target_position_deg` | number | Drive 目标角度 |
| `target_velocity_deg_s` | number | Drive 目标角速度 |
| `stiffness` | nonnegative number | 位置刚度 |
| `damping` | nonnegative number | 速度阻尼 |
| `max_force` | nonnegative number/null | 最大驱动力；`null` 表示不显式写入 |

### 2.12 `physics_scene`

| 参数 | 类型 | 含义 |
|---|---|---|
| `author_in_asset` | bool | 是否在可复用资产中创建 PhysicsScene |
| `prim_path` | absolute prim path | PhysicsScene 路径 |
| `gravity_direction` | vec3 | 重力方向，构建器应归一化或校验 |
| `gravity_magnitude` | nonnegative number | 重力加速度 |
| `time_steps_per_second` | positive integer | 物理仿真频率 |

可复用模型建议 `author_in_asset=false`，由最终组合场景统一提供 PhysicsScene。

### 2.13 `semantics`

| 参数 | 类型 | 含义 |
|---|---|---|
| `enabled` | bool | 全局语义开关 |
| `api` | string | 目标语义 API 名称 |
| `instance_name` | string | 多应用 API 的实例名 |
| `apply_to` | enum | 语义应用位置；当前为 `gaussian_prim` |
| `allow_duplicate_labels` | bool | 是否允许多个部件共享同一标签 |
| `apply_to_mesh` | bool | 是否也给隐藏 Mesh 添加语义 |

### 2.14 `outputs`

| 参数 | 类型 | 含义 |
|---|---|---|
| `entry_file` | filename | 最终独立入口 USD |
| `visual_layer_file` | filename | 3DGS、显示和语义层 |
| `physics_layer_file` | filename | RigidBody、Mass、Joint、Articulation 层 |
| `mesh_layer_file` | filename | 输出 Mesh 层 |
| `gaussian_parts.one_file_per_part` | bool | 每个 Gaussian 是否单独写一个 USD |
| `gaussian_parts.directory` | relative path | Gaussian 子文件输出目录 |
| `gaussian_parts.file_format` | enum | `usda` 或 `usdc` |
| `use_relative_asset_paths` | bool | 输出 USD 内引用是否使用相对路径 |
| `write_resolved_config` | bool | 是否写出继承、路径和引用都已解析的配置快照 |
| `resolved_config_file` | filename | 解析配置文件名 |
| `write_validation_report` | bool | 是否写出构建和校验报告 |
| `validation_report_file` | filename | 校验报告文件名 |
| `write_debug_stage` | bool | 是否生成用于人工检查的调试 Stage |
| `debug_stage_file` | filename | 调试 Stage 文件名 |
| `overwrite_policy` | enum | `error`、`replace` 或 `skip`；推荐默认 `error` |

`replace` 会覆盖现有输出，属于需谨慎使用的显式策略；构建器实施时应先解析精确目标并限制在 `output_directory` 内。

### 2.15 `validation`

| 参数 | 类型 | 含义 |
|---|---|---|
| `strict_mode` | bool | 是否执行完整结构和数值校验 |
| `expected_counts.enabled_links` | integer/null | 预期启用 Link 数量；`null` 表示动态 |
| `expected_counts.enabled_joints` | integer/null | 预期启用 Joint 数量 |
| `expected_counts.enabled_gaussian_parts` | integer/null | 预期启用 3DGS 数量 |
| `expected_counts.enabled_mesh_parts` | integer/null | 预期启用 Mesh 数量 |
| `require_unique_ids` | bool | 要求同类对象 ID 唯一 |
| `require_unique_prim_paths` | bool | 要求最终完整 Prim 路径唯一 |
| `require_existing_input_files` | bool | 要求全部启用输入文件存在 |
| `require_every_part_has_link` | bool | 要求每个启用 Mesh/3DGS 属于有效 Link |
| `require_joint_bodies_resolve_to_links` | bool | Joint 两端必须解析为刚体 Link |
| `require_connected_articulation` | bool | 启用 Link 和 Joint 必须形成一个连通图 |
| `required_topology` | enum | `chain`、`tree` 或 `any_connected` |
| `require_finite_joint_limits` | bool | 启用限位时必须为有限数 |
| `require_positive_mass` | bool | Link 质量必须大于零 |
| `require_positive_diagonal_inertia` | bool | 三个对角惯量必须大于零 |
| `max_joint_fit_rms_error_m` | number/null | 允许的关节圆/平面拟合 RMS 误差上限 |
| `max_mesh_gaussian_bounds_difference_m` | number/null | 同 Link Mesh 和 Gaussian 包围盒差异上限 |
| `fail_on_warning` | bool | 是否将所有警告提升为构建失败 |

`required_topology=chain` 时，除链两端外，每个启用 Link 的有效关节度数应为 2；不存在环和分支。以后需要属具分支时可改为 `tree`。

### 2.16 `execution`

| 参数 | 类型 | 含义 |
|---|---|---|
| `dry_run` | bool | 只解析和校验，不写 USD 资产 |
| `log_level` | enum | `DEBUG`、`INFO`、`WARNING` 或 `ERROR` |
| `stop_after_phase` | string/null | 在指定构建阶段完成后停止，用于调试；`null` 表示完整执行 |

| 参数 | 类型 | 含义 |

#### `fit`

| 参数 | 类型 | 含义 |
|---|---|---|
| `selected_point_count` | integer/null | 实际参加拟合的点数 |
| `circle_radius_m` | number/null | 拟合圆半径 |
| `plane_rms_error_m` | number/null | 选点到拟合平面的 RMS 误差 |

## 4. 模板中仍需替换的内容

模板只给出五个示例 Gaussian，而远端资产的实际 3DGS 数量可以不同。正式配置时需要：

1. 将每个实际 PLY 逐条加入 `gaussian.parts`；
2. 设置每个 PLY 的唯一 ID、真实文件名、所属 Link 和语义标签；
3. 为每个逻辑 Mesh 设置正确的 `reference_gaussian_part_ids`；
4. Fangshan 首次迁移时用一次性旧 Joint 帧换算结果和 Mesh 验证结果替换 `center=null`、`axis=null`；其他资产使用独立标定结果；
5. 将 Fangshan 每个 Joint 的 `body0/body1` 设置为直接 `link` 引用，并确认 body 顺序、轴方向、零位和限位；
6. 确认 Mesh 数值单位比例，不能只依据源 USD 的 `metersPerUnit` 元数据猜测；
7. 根据使用环境设置新的根 Prim、输出路径和采集配置。

### 4.1 旧 Joint 数值的一次性使用边界

旧 `Excavator_Fangshan_01.usda` 只在本次旧模型转新模型时由独立迁移工具显式读取。旧 localPos/localRot 必须先恢复为旧世界关节旋转线，再去除旧视觉子 Prim 的公共变换，才能得到当前源 PLY/Mesh 数值坐标中的 `center` 和 `axis`。

迁移并验证后的数值写入新标定文件。此后：

- 正常构建器只读取新主配置和新标定文件；
- 重复构建、换输出目录和部署都不读取旧 USD；
- 标定缺失时直接报错，不允许自动回退到旧模型；
- 旧 USD 的路径和 Prim 路径不进入正式配置协议；
- 迁移证据报告可保留旧文件 SHA-256、诊断路径和变换过程，用于审计。
