## 修改边界

- 新增源码位于 `scripts/260922CloudInstanceOps/`；安装目标是用户目录内原有 Skill。
- 未安装或升级系统/项目依赖；使用本地已有 Python 3.9.18 和 Paramiko 2.8.1。Paramiko 测试导入出现已有 Blowfish 弃用警告，没有因此修改全局依赖。

- 没有安装后台监控、计划任务或启动项；没有发起第三方上传、杀毒扫描或自动文件处置。
- 远端操作及公开文档下载均为功能验收；在线连接可自然产生访问日志。

## 剩余边界

这是一套可审计的操作入口，不是强制隔离。root 执行权限未降低；同 Windows 用户程序仍可能访问凭据；秘密模式匹配不能覆盖任意业务内容。SSH 脚本内部联网、其他终端、后台进程与人工操作不自动进入完整流量审计。`access-note` 是有来源的自报登记。哈希链不能抵抗日志整体删除或完整重写，离线/独立日志服务尚未实施。

出现超时应先核对远端状态再重试；日志写失败时停止后续动作。后续敏感上传、系统改动和来源范围扩展继续遵循用户当次授权，不因为安装工具而获得额外权限。
